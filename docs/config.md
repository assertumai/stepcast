# Конфигурация

Два уровня:

| Файл | Область | В git |
|---|---|---|
| `~/.scarp/config.yml` | машина: пути, бэкенды, политика | нет |
| `.scarp/config.yml` | проект: умолчания и ужесточения | да |

Проектный конфиг перекрывает глобальный, пайплайн перекрывает оба, флаги CLI
перекрывают всё. Из этого правила два исключения — `env_deny` и `limits`, они
работают в обратную сторону: нижний уровень может только ужесточить.

Причина исключения простая: политика, которую отменяет тот, кого она
ограничивает, — не политика. Глобальный конфиг задаёт пол, всё остальное может
поднять его выше, но не опустить.

## Формат

```yaml
version: 1
kind: config

runs:
  root: ~/.scarp/runs
  keep: 30d                    # scarp gc удаляет прогоны старше
  keep_summaries: forever      # run.json / status.json / usage.json остаются

defaults:
  agent: claude
  model: sonnet
  workspace: worktree
  concurrency: 3
  env_inherit: minimal

limits:                        # потолки, которые пайплайн не может поднять
  tokens: 5M
  wallclock: 4h
  concurrency: 8
  attempts: 5
  iterations: 10

env_deny:                      # объединяется со всеми уровнями ниже
  - "*_TOKEN"
  - "*_SECRET"
  - "*_PASSWORD"
  - "*_API_KEY"
  - "*_PRIVATE_KEY"
  - "*_CREDENTIALS"
  - "AWS_*"
  - "SSH_*"
  - "KUBECONFIG"

context:
  inline_threshold: 4k         # выше порога файл передаётся ссылкой
  deny:                        # объединяется со всеми уровнями ниже
    - "**/.env*"
    - "**/*.pem"
    - "**/*.key"
    - "**/id_rsa*"
    - "**/.git/**"

backends:
  claude:
    command: claude
    passthrough: [HOME, CLAUDE_CONFIG_DIR]
    cache_read_weight: 0.1     # с каким весом cache_read идёт в бюджет
    default_model: sonnet
    concurrency: 2             # одновременных вызовов этого бэкенда
  codex:
    command: codex
    enabled: false

ui:
  port: 7717
  open: false
```

## Что где уместно

**Глобальный** — всё, что относится к машине и к политике: где лежат бэкенды,
их веса и лимиты параллелизма, корень директории прогонов, retention, базовые
запреты окружения, потолки `limits`.

**Проектный** — умолчания команды: какой агент и модель по умолчанию, какой
`workspace`, дополнительные запреты окружения под специфику проекта. Он лежит в
репозитории и попадает в ревью, поэтому секретов и машинно-зависимых путей в
нём быть не должно — линтер отклоняет `runs.root` и `backends.*.command` в
проектном конфиге.

## Запреты окружения

`env_deny` из глобального конфига, проектного конфига и пайплайна
объединяются в один список. Он применяется последним шагом сборки окружения и
вычёркивает переменные независимо от того, как они туда попали — включая
`env_passthrough`, `env_files` и явный `env` шага.

Базовый список выше ловит распространённые схемы именования учётных данных.
Он намеренно широкий: при `env_inherit: minimal` большинство переменных и так
не проходит, а запрет страхует случаи, когда кто-то включил `full` или
подцепил `.env` с лишним содержимым.

Обойти запрет из пайплайна нельзя. Если переменная нужна — либо она правится в
глобальном конфиге, либо передаётся как секрет через `secrets:`, где у неё есть
маскирование в логах и точечная выдача.

## Запреты контекста

`context.deny` работает по тому же правилу, но по путям файлов: перечисленное
не попадает в контекст агентского шага, даже если объявлено явно или поймано
глобом. Списки со всех уровней объединяются и снизу не отменяются.

Это отдельный от `env_deny` контур, потому что утечки идут разными путями:
переменная окружения попадает в подпроцесс, а файл — в промпт и, значит, в
`prompt.txt` на диске и в окно модели.

`context.inline_threshold` разделяет два способа передачи: файл меньше порога
вставляется в промпт целиком, больший передаётся ссылкой на путь, и агент
читает его сам, если сочтёт нужным.

## Потолки

`limits` — верхняя граница для значений пайплайна. Пайплайн, объявивший
`budget.tokens: 8M` при `limits.tokens: 5M`, отклоняется линтером, а не молча
урезается: тихое урезание превращает объявленный бюджет в ложь.

`limits.attempts` и `limits.iterations` ограничивают `attempts.max` и
`until.max_iterations`. Вместе с обязательным бюджетом пайплайна это второй
предохранитель против неограниченных повторов.

## Разрешение

```
$ scarp config
defaults.agent        claude       .scarp/config.yml
defaults.model        opus         --model (флаг)
runs.root             ~/.scarp/runs  ~/.scarp/config.yml
limits.tokens         5M           ~/.scarp/config.yml
env_deny              14 шаблонов  ~/.scarp/config.yml (9) + .scarp/config.yml (3) + pipeline (2)
```

Команда печатает итоговую конфигурацию с происхождением каждого значения. Тот
же принцип, что и с объяснением инвалидации: настройка, про которую непонятно,
откуда она взялась, обходится дороже, чем её отсутствие.
