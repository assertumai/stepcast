# Примеры

**`minimal/`** — запускается текущим срезом целиком:

```bash
stepcast run examples/minimal/stepcast.yml --input topic=сессии
```

Показывает общую сессию агентских шагов, структурированный выход работы,
автоматическую передачу выхода в контекст следующей работы, предикаты и
разбор отказа.

**`acceptance/`** — приёмка цикла `until` на живом бэкенде:

```bash
stepcast run examples/acceptance/stepcast.yml
node examples/acceptance/verify.mjs <каталог-прогона-из-вывода>
```

Число итераций задаёт счётчик в файле, а не модель, поэтому прогон
детерминирован: ровно две итерации, один короткий агентский вызов в каждой,
потолок 40k токенов. `verify.mjs` читает журнал и сверяет предел итераций,
сброс сессий и попыток, раскладку `iter-N` и её отсутствие у работы без цикла —
двенадцать проверок, каждая с внятным исходом.

После прогона в рабочем каталоге остаётся служебный `.stepcast-счётчик` — его
можно удалить.

**`target-state/`** — целевое состояние формата. **Не запускается**: использует
подстановку в числовые поля, `on_exceed: wait` и предикат `judge`, которых в
текущем срезе нет, — движок отклонит его с указанием, чего не хватает. Лежит
здесь как образец того, к чему формат идёт, — см.
[состояние реализации](../docs/status.md).
