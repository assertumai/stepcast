# Примеры

**`minimal/`** — запускается текущим срезом целиком:

```bash
stepcast run examples/minimal/stepcast.yml --input topic=сессии
```

Показывает общую сессию агентских шагов, структурированный выход работы,
автоматическую передачу выхода в контекст следующей работы, предикаты и
разбор отказа.

**`acceptance/`** — приёмка цикла `until` на живом бэкенде:

```bash
stepcast run examples/acceptance/stepcast.yml
node examples/acceptance/verify.mjs <каталог-прогона-из-вывода>
```

Число итераций задаёт счётчик в файле, а не модель, поэтому прогон
детерминирован: ровно две итерации, один короткий агентский вызов в каждой,
потолок 40k токенов. `verify.mjs` читает журнал и сверяет предел итераций,
сброс сессий и попыток, раскладку `iter-N` и её отсутствие у работы без цикла —
двенадцать проверок, каждая с внятным исходом.

После прогона в рабочем каталоге остаётся служебный `.stepcast-счётчик` — его
можно удалить.

**`codex/`** — приёмка адаптера Codex, поставляемого плагином. Требует
установленного и аутентифицированного `codex` и запускается из временного
проекта, объявляющего плагин, — порядок в [`codex/README.md`](codex/README.md).
Проверяет структурированный вывод, судью и продолжение нити в общей сессии.

**`widgets/`** — образец виджета спайка `ui-runtime-widget-spike`. Скопируйте
`clock.tsx` в `<проект>/.stepcast/widgets/`, откройте демон и экран «Виджеты»
— подробности и границы спайка в [`docs/widgets.md`](../docs/widgets.md).

**`plugins/`** — образцы обеих половин плагина:

- движковая половина (`docs/plugins.md`, «Два подпутя»): `typed/` — доменный
  вклад (предикат и вид шага) через `stepcast/pipeline`, с хелперами
  `define*` и схемой, выведенной из одной zod-модели; `command/` — плагин,
  знающий только ядро (`stepcast/plugin`) и вносящий одну команду. Оба входят
  в `npm run typecheck:plugin` — тем же механизмом, каким подпуть разрешится
  у стороннего автора, после `npm run build`.
- браузерная половина (`docs/ui-plugins.md`): `board/` — на React, с
  компонентами `@stepcast/ui` (Button, Card, Table, Dialog, Tabs, Select,
  Input) и вкладом в `SCREEN` дескриптором из `@stepcast/slots`; `element/` —
  на другом фреймворке (Preact), встаёт в слот пользовательским элементом
  через адаптер `elementSlotComponent`, не импортируя ни React, ни cordis.
  Скопируйте каталог в `~/.stepcast/plugins/<id>/` рядом с `plugin.json` —
  демон соберёт и отдаст браузерную половину сам.

**`target-state/`** — целевое состояние формата. **Не запускается**: использует
подстановку в числовые поля, `on_exceed: wait` и предикат `judge`, которых в
текущем срезе нет, — движок отклонит его с указанием, чего не хватает. Лежит
здесь как образец того, к чему формат идёт, — см.
[состояние реализации](../docs/status.md).
