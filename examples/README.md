# Примеры

**`minimal/`** — запускается текущим срезом целиком:

```bash
scarp run examples/minimal/scarp.yml --input topic=сессии
```

Показывает общую сессию агентских шагов, структурированный выход работы,
автоматическую передачу выхода в контекст следующей работы, предикаты и
разбор отказа.

**`target-state/`** — целевое состояние формата. Использует `until` и
`on_exceed: wait`, которых в текущем срезе нет, поэтому **не запускается**:
движок отклонит его с указанием, чего не хватает. Лежит здесь как образец
того, к чему формат идёт, — см. [состояние реализации](../docs/status.md).
