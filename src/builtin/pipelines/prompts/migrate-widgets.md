# Миграция виджетов

Таблица общих модулей витрины сменилась. Обзор состава виджетов проекта —
вывод работы `survey` (`stepcast widgets --json`) — уже дан тебе результатом
предшествующей работы: у каждого виджета названы его файл, голые
спецификаторы, которые он импортирует, и — если он устарел — имена, которых
действующая таблица больше не несёт.

## Какие виджеты трогать

Вход `widget` этого запуска — "${params.widget}" (пустая строка значит, что
вход не назван).

- Если вход назвал конкретный id — работай только с ним, даже если
  сканирование импортов не считает его устаревшим (таблица могла не поменять
  сам специфик, а сменить смысл внутри оставшегося имени — это сканирование
  не ловит).
- Если вход равен `all` — обойди все виджеты проекта.
- Если вход пуст — обойди только те, что обзор назвал устаревшими.
- Обзора без единого подходящего виджета достаточно, чтобы завершить работу
  без единого вызова `propose`.

## Что делать с каждым виджетом

1. Прочитай файл виджета (путь — из обзора).
2. Поправь голые импорты, которых таблица больше не несёт, — заметки о смене
   имени (текст рядом с каждым устаревшим именем в обзоре) говорят, на что
   заменить. Больше в файле ничего не трогай: одна правка — одна причина.
3. Запиши исправленный файл целиком в `$STEPCAST_SCRATCH/<id>.tsx` — не в
   рабочее дерево: `Edit`/`Write` над ним у этого шага нет вовсе, дверь в
   кабинет — только команда `propose`.
4. Поставь исправленную версию в очередь — ровно этой формой вызова:

   ```
   node "$STEPCAST_BIN" propose .stepcast/widgets/<id>.tsx --from "$STEPCAST_SCRATCH/<id>.tsx" --reason "<что изменилось и почему>"
   ```

   Движок зовётся через `node "$STEPCAST_BIN"`, а не голым `stepcast`: у
   движка прогона исполняемый бит не гарантирован, в `PATH` его может не быть
   вовсе (движок этого прогона — снимок в каталоге прогона), и право шага
   выписано ровно на эту форму — другая будет отклонена.

   По разу на файл. Причина — короткая, по существу: какое имя ушло и чем
   заменено.

Ничего, кроме `propose`, кабинет не меняет. Диф решит человек на экране
«Предложения» — твоя задача заканчивается постановкой в очередь.
