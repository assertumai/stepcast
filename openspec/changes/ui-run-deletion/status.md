## Работает

- **Витрина**: удаление прогона из истории целиком — поштучно (`DELETE /api/run`) и группой по списку адресов (`DELETE /api/runs`), с исходом на каждый адрес и суммой освобождённого места; живость прогона определяется тем же правилом, что и в движке — процессом из манифеста, а не статусом `running`, поэтому прогон, застрявший в `running` после гибели процесса, теперь удаляется наравне с завершённым, а идущий и спящий по-прежнему отклоняются кодом `409`; отбор прогонов к групповому удалению (`GET /api/runs`) по признакам — оборванные, отказавшие, старше срока — объединённым по «или», по всем проектам или одному, с размером и числом до подтверждения и без изменений на диске; прогон с испорченным журналом из отбора не выпадает — статус берётся из манифеста, возраст считается по времени каталога, и такой прогон помечен нечитаемым; обзор несёт признак оборванности прогона отдельно от `running`
