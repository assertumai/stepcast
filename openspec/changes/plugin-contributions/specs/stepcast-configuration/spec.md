## ADDED Requirements

### Requirement: Ключ plugins складывается между слоями

Конфигурация SHALL принимать ключ `plugins` — список строк — в глобальном и проектном слоях. Значения слоёв MUST объединяться в порядке «глобальный, затем проектный» с сохранением порядка внутри слоя; повтор строки MUST схлопываться в одно вхождение. Пустой список MUST отклоняться разбором как объявление, не объявляющее ничего. Требование MUST быть выражено в публикуемой JSON Schema конфигурации.

#### Scenario: Объединение слоёв

- **WHEN** глобальный слой объявляет `plugins: ["a"]`, проектный — `plugins: ["b", "a"]`
- **THEN** действующий список — `["a", "b"]`

#### Scenario: Пустой список

- **WHEN** конфигурация содержит `plugins: []`
- **THEN** чтение конфигурации завершается ошибкой, называющей файл и ключ

### Requirement: Отчёт о конфигурации показывает плагины и их умолчания

Отчёт `stepcast config` SHALL показывать вклад каждого слоя в список `plugins` по образцу складывающихся списков и SHALL печатать раздел о загруженных плагинах. Значение, полученное из умолчаний плагина, MUST показываться с источником `plugin:<имя плагина>`.

#### Scenario: Источник умолчания плагина

- **WHEN** `backends.codex.sessions` получено из умолчаний плагина `codex-adapter`
- **THEN** отчёт показывает значение с источником `plugin:codex-adapter`
