## ADDED Requirements

### Requirement: Запись работы несёт объявленную дорожку

Запись работы в состоянии прогона SHALL нести необязательное поле `lane` со значением дорожки, объявленной на месте подключения этой работы. У работы без объявленной дорожки поле MUST отсутствовать, а не быть пустой строкой. Запись прежней формы, поля не несущая, MUST читаться как работа без дорожки, а не отклоняться.

#### Scenario: Работа объявила дорожку

- **WHEN** работа подключена с `lane: a` и исполнена
- **THEN** её запись в `status.json` несёт `lane: a`

#### Scenario: Работа дорожки не объявляла

- **WHEN** работа подключена без `lane`
- **THEN** её запись поля `lane` не содержит

#### Scenario: Состояние прежней формы

- **WHEN** читается `status.json`, записанный до появления дорожек
- **THEN** его работы читаются как работы без дорожки, а разбор не отказывает

## MODIFIED Requirements

### Requirement: Отчёт о расходе

Команда `stepcast usage` SHALL показывать расход прогона с разбивкой по работам и
шагам и распределением по номеру попытки. Измерения, не сообщаемые бэкендом,
MUST помечаться как отсутствующие.

Если хотя бы одна работа прогона объявляла дорожку, отчёт MUST нести строку
итога по каждой дорожке над строками её работ — по тем же измерениям, что и у
работы, с той же пометкой несообщённого вместо нуля. Работы без дорожки MUST
оставаться вне группировки и печататься как сегодня. Прогон, в котором дорожек
не объявлял никто, MUST печататься без группировки вовсе.

#### Scenario: Шаги, проходящие не с первой попытки

- **WHEN** пользователь запрашивает отчёт о расходе
- **THEN** видно, какие шаги завершались успехом не с первой попытки и сколько это стоило

#### Scenario: Неполный учёт помечен

- **WHEN** бэкенд не сообщает одно из измерений расхода
- **THEN** отчёт помечает это измерение как несообщаемое, а не выводит ноль

#### Scenario: Расход по дорожкам

- **WHEN** прогон исполнил две дорожки и пользователь запрашивает отчёт о расходе
- **THEN** отчёт несёт итог каждой дорожки — токены, кеш, время, цену — над разбивкой по её работам

#### Scenario: Несообщённое в итоге дорожки

- **WHEN** цену не сообщила ни одна попытка работ дорожки
- **THEN** в итоге дорожки на месте цены стоит пометка несообщённого, а не ноль

#### Scenario: Прогон без дорожек

- **WHEN** ни одна работа прогона не объявляла дорожку
- **THEN** отчёт печатается без группировки по дорожкам
