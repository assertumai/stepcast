## ADDED Requirements

### Requirement: Работа объявляет дорожку

Обвязка работы SHALL принимать необязательный ключ `lane` со значением-слагом в kebab-case, называющим дорожку, к которой относится работа. Дорожка MUST быть только меткой группировки: на порядок исполнения, вычисление `on` и `if`, выбор рабочей директории и статусы работы она влиять не MUST. Значение, не проходящее правило kebab-case, MUST отклоняться `stepcast lint` ошибкой, называющей работу и встреченное значение. Связность работ одной дорожки зависимостями валидатор требовать не MUST.

#### Scenario: Дорожка объявлена

- **WHEN** пайплайн подключает работу с `lane: a`
- **THEN** `stepcast lint` завершается успехом, а работа относится к дорожке `a`

#### Scenario: Значение не слаг

- **WHEN** работа подключена с `lane: "Дорожка A"`
- **THEN** `stepcast lint` завершается ошибкой, называющей работу и встреченное значение

#### Scenario: Дорожка не меняет порядок

- **WHEN** две работы объявляют одну дорожку и не связаны `needs`
- **THEN** порядок их исполнения определяется графом так же, как без `lane`

#### Scenario: Дорожка попадает в зафиксированный пайплайн

- **WHEN** прогон фиксирует раскрытый пайплайн
- **THEN** `pipeline.lock.yml` содержит объявленные значения `lane`

## MODIFIED Requirements

### Requirement: Обвязка запрещена внутри файла работы

Ключи `needs`, `on`, `if`, `lane` и `with` SHALL отклоняться внутри документа с
`kind: job`. Связи, условия и принадлежность дорожке MUST описываться только на
месте подключения: файл работы подключается несколькими дорожками, и объявить
дорожку внутри него нельзя по построению.

#### Scenario: needs в файле работы

- **WHEN** файл работы содержит `needs: [plan]`
- **THEN** `stepcast lint` завершается ошибкой и указывает файл и ключ

#### Scenario: lane в файле работы

- **WHEN** файл работы содержит `lane: a`
- **THEN** `stepcast lint` завершается ошибкой и указывает файл и ключ
