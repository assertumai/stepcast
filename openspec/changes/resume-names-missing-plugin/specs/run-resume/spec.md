## ADDED Requirements

### Requirement: Возобновление раскрывает пайплайн загруженными плагинами и называет недостающий

Возобновление SHALL раскрывать пайплайн исходного прогона реестром вкладов,
загруженным для текущего вызова команды, а не одними только встроенными
вкладами — плагинный предикат, чей плагин загружен, MUST NOT отклоняться
разбором документа как неизвестный ключ. Манифест исходного прогона,
называющий плагин, отсутствующий в загруженном реестре, MUST приводить к
отказу до разбора документа схемой; отказ MUST называть имя, версию и путь
модуля (`source`) каждого такого плагина из манифеста. Сообщение о неизвестном
ключе схемы с подсказкой сверяться с форматом пайплайна MUST оставаться
диагностикой для документа, чей манифест не называет плагины вовсе либо
называет только те, что загружены.

#### Scenario: Плагин загружен — возобновление раскрывает пайплайн

- **WHEN** манифест исходного прогона называет плагин, и тот же плагин загружен в реестр текущего вызова возобновления
- **THEN** пайплайн раскрывается без отказа, и плагинный предикат документа проходит разбор наравне со встроенными

#### Scenario: Плагин не загружен — отказ называет его по манифесту

- **WHEN** манифест исходного прогона называет плагин, отсутствующий в реестре текущего вызова возобновления
- **THEN** возобновление отказывает сообщением, называющим имя, версию и путь модуля этого плагина из манифеста
- **AND** сообщение не содержит текста «неизвестный ключ» и подсказки сверяться с форматом пайплайна

#### Scenario: Манифест не называет плагины — прежняя диагностика

- **WHEN** манифест исходного прогона не содержит поля с загруженными плагинами (журнал прежней версии), а документ использует ключ, схемой не распознанный
- **THEN** возобновление отказывает сообщением о неизвестном ключе с подсказкой сверяться с форматом пайплайна, как до этого изменения

#### Scenario: Опечатка в предикате при полном составе плагинов

- **WHEN** все плагины, названные манифестом исходного прогона, загружены в реестр, а документ использует ключ предиката, не предоставленный ни одним из них
- **THEN** возобновление отказывает сообщением о неизвестном ключе, а не сообщением о недостающем плагине
