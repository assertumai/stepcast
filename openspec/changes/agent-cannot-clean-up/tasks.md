# Задачи

Порядок снизу вверх: сначала каталог заводится, потом его путь доходит до шага
двумя каналами, потом бэкенду объявляется доступ, и только после этого петля
переводится на новый каталог. Каждая задача — код **и** тест; тест обязан
падать до правки.

Границу `changed_only` захода расширять не нужно: `.stepcast/**`, `docs/**`,
`src/**`, `test/**` и `openspec/changes/**` уже в ней.

## 1. Каталог черновиков в раскладке прогона

- [x] 1.1 Добавить путь каталога черновиков работы в `src/core/journal/paths.ts`
      — функцией рядом с `jobDir`, дающей `<run_dir>/jobs/<id>/scratch`.
      Критерий: путь считается по тем же входам, что и `jobDir`, и лежит
      целиком внутри дерева прогона при любом режиме `workspace`.
- [x] 1.2 Заводить каталог в `prepareJob` (`src/core/journal/writer.ts`) вместе
      с каталогом работы, с теми же правами (`0700`). Критерий: каталог
      существует до первого шага работы, даже если ни один шаг к нему не
      обратится.
- [x] 1.3 Снимать пустой каталог по завершении работы — там же, где работа
      получает финальный статус (`src/core/run/runner.ts`). Критерий: работа,
      ничего не записавшая, каталога после себя не оставляет; работа,
      записавшая хоть один файл, оставляет его нетронутым. Отказ удаления не
      меняет статуса работы: уборка журнала — учётная операция, и её неудача
      идёт в `bookkeeping.failed`, а не в исход.
- [x] 1.4 Тест (`test/scratch.test.ts`): каталог заведён до первого шага; лежит
      вне рабочего дерева в режимах `cwd`, `worktree` и `copy`; пустой снят по
      завершении работы; непустой сохранён; отказ удаления работу не роняет.

      проверки цикла и прочих. Критерий: переменная приходит и агентскому, и

## 5. Границы правок не срываются на черновиках

- [x] 5.1 Тест (`test/changed-only.test.ts`): шаг, записавший файлы в каталог
      черновиков и не тронувший рабочее дерево за объявленными границами,
      проходит `changed_only`, а записанные пути в результате предиката не
      перечислены. Тест воспроизводит отказ захода `616c1b` и обязан падать
      на сегодняшнем поведении, если черновик кладётся в дерево, — то есть
      покрывает обе стороны: черновик в каталоге проходит, черновик в дереве
      по-прежнему проваливает предикат.
- [x] 5.2 Проверить, что правки в `src/core/expect/evaluate.ts` не
      потребовалось: каталог вне дерева в якорь не входит. Если тест 5.1
      показал обратное — чинить причину в снятии якоря, а не ослаблять
      предикат списком исключений.
