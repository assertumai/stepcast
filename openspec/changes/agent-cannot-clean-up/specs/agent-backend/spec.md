## ADDED Requirements

### Requirement: Каталог черновиков доступен агенту в жёстком режиме

Адаптер SHALL объявлять бэкенду каталог черновиков работы доступным для чтения и записи, когда шаг исполняется в режиме `enforce: strict` и бэкенд ограничивает агента рабочей директорией.

Вне жёсткого режима адаптер MUST NOT расширять доступ агента: границы записи там
ставит сам бэкенд по своим настройкам, и система в них не вмешивается.

Расширение MUST ограничиваться этим каталогом: никакой другой путь за пределами
рабочей директории адаптер объявлять доступным не вправе.

#### Scenario: Жёсткий режим объявляет каталог доступным

- **WHEN** агентский шаг исполняется с `enforce: strict`
- **THEN** запуск бэкенда содержит параметр, объявляющий каталог черновиков этой работы дополнительной доступной директорией

#### Scenario: Агент пишет черновик вне рабочего дерева

- **WHEN** агент с `enforce: strict` записывает файл по пути внутри каталога черновиков
- **THEN** запись выполняется, а отказа в разрешении не происходит

#### Scenario: Мягкий режим запуск не меняет

- **WHEN** агентский шаг исполняется без `enforce: strict`
- **THEN** запуск бэкенда собирается так же, как до появления каталога черновиков
