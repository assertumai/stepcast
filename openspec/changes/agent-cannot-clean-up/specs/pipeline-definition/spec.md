## MODIFIED Requirements

### Requirement: Состав пространства run

Пространство `run` SHALL содержать `run.id`, `run.dir`, `run.workspace` и `run.scratch` — идентификатор прогона, директорию его журнала, рабочую директорию работы и её каталог черновиков.

Величины уровня шага пространством `run` не предоставляются: система SHALL
внедрять их переменными окружения `STEPCAST_JOB_DIR` и `STEPCAST_STEP_DIR`.

#### Scenario: Каталог прогона в пути контекста

- **WHEN** запись контекста объявлена как `${run.dir}/item.json`
- **THEN** шаг читает файл из директории журнала прогона

#### Scenario: Каталог черновиков в тексте промпта

- **WHEN** текст промпта агентского шага содержит `${run.scratch}`
- **THEN** агент получает промпт с путём каталога черновиков этой работы

#### Scenario: Обращение к имени вне состава

- **WHEN** значение содержит `${run.step_dir}`
- **THEN** работа завершается отказом с указанием доступных имён пространства
