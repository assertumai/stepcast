## ADDED Requirements

### Requirement: Каталог черновиков работы

Система SHALL заводить каждой работе каталог черновиков вне её рабочего дерева — в дереве журнала прогона, рядом с прочими файлами работы — и заводить его до первого шага, независимо от того, обратится ли к нему хоть один шаг.

Путь каталога MUST попадать в окружение шага переменной `STEPCAST_SCRATCH` на
общих правилах инжектируемых переменных: она не подлежит переопределению
объявленным `env` и не отсекается фильтром `env_deny`.

Каталог MUST быть общим для всех шагов работы, её итераций и попыток: написанное
одним шагом остаётся видимым следующему.

По завершении работы система MUST удалять каталог, если в него ничего не
записано, и MUST сохранять его вместе с остальным журналом прогона, если
записано. Правило MUST действовать при любом исходе работы, включая отказ,
случившийся до первого шага.

#### Scenario: Каталог существует до первого шага

- **WHEN** работа начала исполнение
- **THEN** каталог черновиков существует и доступен для записи
- **AND** он лежит вне рабочего дерева работы при любом режиме `workspace`

#### Scenario: Путь приходит переменной окружения

- **WHEN** шаг исполняется
- **THEN** его окружение содержит `STEPCAST_SCRATCH` с путём каталога черновиков работы

#### Scenario: Переменная не переопределяется

- **WHEN** шаг объявляет `env` с ключом `STEPCAST_SCRATCH`
- **THEN** действующим остаётся значение, подставленное системой

#### Scenario: Каталог общий для шагов работы

- **WHEN** один шаг работы записал файл в каталог черновиков, а следующий шаг той же работы обратился к нему по тому же пути
- **THEN** файл читается

#### Scenario: Пустой каталог не остаётся в журнале

- **WHEN** работа завершилась, не записав в каталог черновиков ничего
- **THEN** каталога в дереве прогона нет

#### Scenario: Работа отказала до первого шага

- **WHEN** работа отказала на подготовке рабочей директории или на раскрытии подстановок, не дойдя ни до одного шага
- **THEN** пустого каталога черновиков в дереве прогона не остаётся

#### Scenario: Записанное сохраняется до уборки

- **WHEN** работа завершилась, оставив в каталоге черновиков файлы
- **THEN** они остаются в дереве прогона и удаляются вместе с прогоном при уборке
