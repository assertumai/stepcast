## ADDED Requirements

### Requirement: Правка патча дерева плагинов действует без перезапуска демона

Демон SHALL считать пригодность удерживаемого ядра проекта по строкам его дерева плагинов — их `id`, модулям, слою-источнику, признаку включённости и порядку, — а не по объявлениям одного лишь ключа `plugins`. Слой-источник входит в сравнение наравне с модулем: относительный модуль разрешается от файла, объявившего строку, и строка с тем же `use`, перешедшая в другой файл, называет уже другой модуль на диске. Правка любого файла, участвующего в сборке дерева, MUST действовать со следующего запроса, без `stepcast down && stepcast up`. Ядро, чьё дерево разошлось с текущим, MUST сниматься: вклады строк, ушедших из дерева, MUST переставать быть доступными, а вклады появившихся строк MUST действовать. Замена модуля в строке MUST подхватываться; изменённый на диске код уже загруженного модуля MUST NOT считаться подхваченным, и это ограничение MUST быть названо в документации вместе с тем, что снимает его перезапуск демона.

#### Scenario: Патч заменил строку на работающем демоне

- **WHEN** проектный патч заменяет строку своим модулем, и страница пайплайнов обновлена
- **THEN** вклады прежнего модуля сняты, вклады нового действуют, а демон не перезапускался

#### Scenario: Патч отключил строку

- **WHEN** проектный патч объявляет действующую строку `enabled: false`, и страница пайплайнов обновлена
- **THEN** вкладов этой строки в реестре проекта больше нет

#### Scenario: Строка перешла из домашнего патча в проектный

- **WHEN** строка с тем же `id` и тем же относительным `use` объявлена вместо домашнего патча проектным, и страница пайплайнов обновлена
- **THEN** ядро пересобрано, и действуют вклады модуля из каталога проекта

#### Scenario: Дерево не изменилось

- **WHEN** правка конфигурации проекта не меняет ни одной строки дерева
- **THEN** ядро проекта остаётся прежним, и модули заново не импортируются
