- [x] 6.4 Предел выдержки объявляется сборке только вместе с самой выдержкой;

- [x] 6.5 Событие об усечении пишется однажды на шаг, а не на каждую попытку;
      отчёт об усечении несёт число отброшенных строк
- [x] 6.6 Тесты: целостность строк проверяется по совпадению с исходными;
      обрезанная длинная строка, тесный предел на восемь предикатов, одно
