## ADDED Requirements

### Requirement: Оглавление и отбор по имени согласованы

Источник знания SHALL разрешать отбором по имени всякий идентификатор, названный его собственным ответом `index`, и MUST отдавать по нему содержимое — записью со ссылкой на путь либо записью с текстом. Оглавление, предлагающее запрашивать содержимое по идентификатору, MUST NOT называть идентификаторов, по которым отбор отказывает: такой промах роняет шаг посреди прогона, а агент следует ровно той инструкции, которую дало само оглавление. Требование контрактное и распространяется на любой источник, включая `cmd`; движок его не проверяет — тем же порядком, каким он не проверяет детерминизм источника.

#### Scenario: Каждое имя из оглавления разрешается

- **WHEN** отбор по имени вызван поочерёдно с каждым идентификатором, названным ответом `index` того же источника
- **THEN** каждый вызов отдаёт хотя бы одну запись и ни один не отказывает

#### Scenario: Имя вне оглавления отказывает внятно

- **WHEN** отбор по имени вызван с идентификатором, которого ответ `index` не называет и которого у источника нет
- **THEN** источник отказывает сообщением, называющим этот идентификатор, а не отдаёт пустой ответ
