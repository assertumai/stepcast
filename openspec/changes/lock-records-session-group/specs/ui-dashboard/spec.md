## ADDED Requirements

### Requirement: Работа прогона показывает объявленную обвязку

Раскрытие прогона SHALL показывать у каждой работы объявленную дорожку (`lane`) и объявленную группу сессий (`session_group`) — там же, где показаны прочие признаки её определения: предшественники, условие и исход, при котором работа запускается.

Оба признака MUST браться из `pipeline.lock.yml` — того же источника, из
которого витрина берёт остальное определение работы, — и MUST отсутствовать в
показе, когда работа их не объявляла: пустое значение MUST NOT показываться
наравне с объявленным. Прогон, чьи файлы убраны и замка не имеет, MUST
показываться без этих признаков и MUST NOT отказывать.

#### Scenario: Группа сессий видна у работы

- **WHEN** раскрыт прогон, работа которого подключена с `session_group: build`
- **THEN** признаки этой работы называют группу сессий `build`

#### Scenario: Дорожка видна у работы

- **WHEN** раскрыт прогон, работа которого подключена с `lane: a`
- **THEN** признаки этой работы называют дорожку `a`

#### Scenario: Необъявленные признаки не показываются

- **WHEN** работа подключена без дорожки и без группы сессий
- **THEN** в её признаках нет ни того, ни другого

#### Scenario: Убранный прогон раскрывается без замка

- **WHEN** раскрыт прогон, у которого `pipeline.lock.yml` снят уборкой
- **THEN** работы показаны без дорожки и группы, а раскрытие не отказывает
