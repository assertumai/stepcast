## ADDED Requirements

### Requirement: Уборка снимает учётные записи рабочих деревьев, заведённых прогоном

Уборка прогона SHALL снимать учётные записи рабочих деревьев, заведённых этим прогоном, — каждую в том репозитории, которому она принадлежит, — до того как удалит каталоги прогона.

Снятие MUST охватывать и корневые деревья работ, и деревья объявленных
вложенных репозиториев внутри них. Перечень снимаемого MUST браться из
состояния прогона, записанного при заведении деревьев, — то есть уборка MUST
быть полной и после отказа прогона, отмены сигналом и остановки по бюджету, а
не только после успешного завершения.

Снятие MUST быть адресным: удаляется учётная запись названного рабочего дерева
и только она. Осиротевшие записи, заведённые не этим прогоном, MUST оставаться
нетронутыми — уборка MUST NOT снимать записи чужого репозитория списком по
признаку осиротелости.

Отказ снятия MUST NOT останавливать удаление прогона и MUST называться в исходе
по этому адресу: неснятая запись, о которой не сказано, — та самая цена, ради
которой ведётся учёт.

Названа MUST быть только запись, которая действительно осталась. Уборка, у
которой снимать уже нечего — тот же прогон убирается повторно, — MUST молчать:
выдуманная утечка обесценивает канал, заведённый ради настоящих.

#### Scenario: Записи прогона сняты

- **WHEN** удаляется прогон, заводивший рабочие деревья с объявленными вложенными репозиториями
- **THEN** учётных записей этих деревьев не остаётся ни в корневом репозитории, ни в репозиториях частей

#### Scenario: Чужие записи не тронуты

- **WHEN** в репозитории объявленной части есть учётная запись рабочего дерева, заведённая не этим прогоном
- **THEN** после уборки прогона она на месте

#### Scenario: Уборка после отказавшего прогона

- **WHEN** удаляется прогон, остановленный отказом, отменой или бюджетом
- **THEN** учётные записи всех заведённых им рабочих деревьев сняты

#### Scenario: Неснятая запись названа

- **WHEN** снятие учётной записи отказало
- **THEN** каталог прогона всё равно удалён, а исход по этому адресу называет неснятую запись

#### Scenario: Повторная уборка не выдумывает неснятых записей

- **WHEN** уже убранный прогон убирается второй раз
- **THEN** исход не называет ни одной неснятой записи
