# Инструменты — по репозиторию, а не одним списком на дерево

## Why

Заход петли саморазвития workspace assertum, взявший пункт в `genatest-studio`,
провалил работу `implement` не сложностью задачи, а правами. Работа объявляет
шагу `Bash(${project.tools} *)`, а `project.tools` — один список на всё дерево
(`[npm, npx, node, yarn, go, git]`). Проверка того же репозитория объявлена
`./gradlew :cli-support:jvmTest …`, и `gradlew` в общий список не входит: гейт
`until.check` движок гоняет своим шагом, вне прав агента, а сам агент повторить
его не может. В журнале захода — десятки `permission.denied` на `./gradlew`,
`java` и обходные попытки; четыре итерации `until` прошли вслепую и заход
остановился.

Проверка (`check`) и практика спецификации (`spec`) у вложенного репозитория
уже свои — их объявляет элемент `project.nested_repos`, и дорожка получает их
параметрами из выхода работы `slots` (`stepcast project repos`). Инструменты
остались единственной величиной этой тройки, которую репозиторий про себя
сказать не может.

## What Changes

- Объектная форма элемента `project.nested_repos` принимает ключ `tools` —
  той же моделью, что `project.tools`. В отличие от `check` и `spec`, перечень
  складывается с корневым, а не замещает его.
- `stepcast project repos` проставляет дорожке `repo.tools` — действующий
  перечень выбранного репозитория. Ключ необязателен: дерево без объявленных
  инструментов отвечает без него.
- Размножение элемента списка по списочной подстановке начинает действовать и
  при позднем раскрытии, а не только при разборе документа. Без этого перечень
  из выхода работы в элемент `allow` не попадает ничем: параметры работы
  скалярны по модели.
- Петля assertum: `genatest-studio` объявляет `./gradlew`, работы `implement` и
  `fix-review` берут инструменты параметром дорожки вместо `${project.tools}`.

## Impact

- `src/core/config/schema.ts`, `src/core/config/resolve.ts` — ключ и его
  приведение.
- `src/core/project/repos.ts` — сложение перечней, единственное место.
- `src/core/backlog/schema.ts` и `schema/*.json` — ключ в блоке `repo`.
- `src/core/pipeline/interpolate.ts` — размножение на позднем раскрытии.
- Совместимость: ключ необязателен, а дерево, его не объявившее, получает
  прежний перечень теми же путями. Правило раскрытия срабатывает только на
  списочном значении, которого в отложенных пространствах петли до этого
  изменения не было.
