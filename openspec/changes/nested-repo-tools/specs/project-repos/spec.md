## ADDED Requirements

### Requirement: Блок repo несёт инструменты выбранного репозитория

Блок `repo`, который `stepcast project repos` проставляет заполненной дорожке, SHALL нести перечень инструментов выбранного репозитория — корневой `project.tools` плюс объявленные самим репозиторием, в этом порядке и без повторов.

Ключ MUST отсутствовать целиком, когда инструментов не объявлено нигде:
пустой перечень доехал бы до списка прав нулём записей, то есть молча снятым
правом, а отсутствующий ключ отказывает по существу — обращением к
несуществующему имени выхода работы.

Отсутствие объявленных инструментов MUST NOT быть отказом команды: `check` и
практика спецификации остаются обязательными, а инструменты нужны только той
работе, которая на них ссылается.

#### Scenario: Пункт назвал вложенный репозиторий

- **WHEN** пункт называет репозиторий, объявивший свои `tools`, а корень объявил свои
- **THEN** блок `repo` несёт `tools` перечнем из обоих, корневые впереди

#### Scenario: Пункт назвал корень

- **WHEN** пункт репозитория не называет либо называет `.`
- **THEN** блок `repo` несёт корневой перечень

#### Scenario: Инструменты не объявлены

- **WHEN** ни корень, ни названный репозиторий инструментов не объявляют
- **THEN** команда отвечает успехом, а ключа `tools` в блоке `repo` нет
