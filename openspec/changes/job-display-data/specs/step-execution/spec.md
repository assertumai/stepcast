## ADDED Requirements

### Requirement: Жёсткий режим доступа неявно разрешает публикацию данных

Движок SHALL добавлять агентскому шагу с `permissions.enforce: strict` право на команду публикации данных работы, не требуя объявлять его в пайплайне.

Право MUST быть узким — ровно на `stepcast data`, а не на `stepcast` целиком:
там `run`, `apply` и `gc`, меняющие мир за пределами шага. Публикация же до
рабочего дерева не дотягивается по устройству: команда не принимает путей и
пишет только в каталог своей работы внутри каталога прогона.

Вне жёсткого режима право MUST NOT добавляться: там отсечения нет вовсе, и
добавлять исключение туда, где оно ничего не меняет, значило бы менять
поведение шага, который `strict` не объявлял.

Уже объявленное явно то же право MUST NOT удваиваться.

#### Scenario: Жёсткий режим

- **WHEN** агентский шаг объявляет `permissions: { allow: [Read], enforce: strict }`
- **THEN** бэкенд получает разрешение и на `Read`, и на команду публикации данных

#### Scenario: Обычный режим

- **WHEN** тот же шаг объявлен без `enforce: strict`
- **THEN** список разрешений остаётся ровно объявленным
