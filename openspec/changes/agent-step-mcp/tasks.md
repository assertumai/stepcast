## 10. Правки по ревью

- [x] 10.1 `--strict-mcp-config` собирается только для бэкенда с объявленной
  возможностью — как соседние флаги в той же `launch` под своими
  возможностями. Названо в `design.md` (решение 6), в дельта-спеке и в
  `docs/config.md`; покрыто тестом.
- [x] 10.2 Дельта-спека `agent-backend` приведена в соответствие с решением 4:
  шаг без объявления запускается прежними параметрами, только если не действует
  `strict`; отсечение под `strict` без объявления описано отдельным сценарием.
- [x] 10.3 Разбор `mcp_servers` мягок в ту сторону, которую велит `design.md`:
  элемент без строковых `name` и `status` означает «состав не сообщён» для
  всего списка, а не «сервер не поднялся». Покрыто тестом на разбор и на
  попытку.
- [x] 10.4 Передача объявления шага в `adapter.launch` покрыта сквозным тестом
  через `invocations` фейкового бэкенда — в обе стороны (объявление доходит,
  необъявленное не появляется).
- [x] 10.5 Сценарий «Пайплайн без объявлений не задет» закреплён эталоном
  состава замка, а не сравнением проекта с самим собой.
- [x] 10.6 Сценарии «Вызов инструмента сервера» и «Отказ в разрешении на
  инструмент сервера» покрыты: разбор `mcp__*` витриной
  (`test/ui-transcript.test.ts`) и событие `permission.denied` на инструменте
  сервера (`test/journal.test.ts`).
- [x] 10.7 Пустое объявление (`mcp: {}`) не требует возможности бэкенда: ни
  ворота прогона, ни линт на нём не срабатывают. Названо в `design.md`, в обеих
  дельта-спеках и в документации; покрыто тестами.
