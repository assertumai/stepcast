## MODIFIED Requirements

### Requirement: Ключ шага вычисляется, записывается и определяет переиспользование

Для каждого шага система SHALL вычислять ключ от нормализованного определения шага, развёрнутых промпта и контекста, идентификатора и версии бэкенда, модели, выходов работ выше по графу и отпечатка входов шага, и записывать его в `step.json`. Вычисленный ключ SHALL быть единственным основанием для решения о
переиспользовании результата шага из другого прогона. Отпечаток входов и его
происхождение MUST записываться рядом с ключом, чтобы решение о валидности
можно было объяснить без повторного вычисления.

Действующее для шага объявление MCP-серверов MUST входить в его нормализованное
определение, а потому в ключ: набор внешних инструментов, доступных агенту, —
условие исполнения шага наравне с промптом и правами. Появление, снятие или
правка объявления MUST менять ключ затронутых шагов, и шаг, исполненный с
другим набором серверов, MUST NOT переиспользоваться.

#### Scenario: Одинаковые условия дают одинаковый ключ

- **WHEN** шаг исполняется дважды на неизменном рабочем дереве с теми же входами
- **THEN** вычисленные ключи совпадают

#### Scenario: Изменение промпта меняет ключ

- **WHEN** изменён файл промпта шага
- **THEN** вычисленный ключ отличается от предыдущего

#### Scenario: Изменение рабочего дерева меняет ключ

- **WHEN** между прогонами изменён файл, входящий в отпечаток входов шага
- **THEN** вычисленный ключ отличается от записанного в прошлом прогоне

#### Scenario: Совпадение ключа — основание для переиспользования

- **WHEN** ключ шага совпал с ключом успешного шага исходного прогона
- **THEN** шаг признан валидным и его результат берётся из исходного прогона

#### Scenario: Решение объяснимо по записи

- **WHEN** шаг признан невалидным
- **THEN** его запись содержит отпечаток входов и его происхождение, достаточные, чтобы назвать причину

#### Scenario: Объявление сервера меняет ключ

- **WHEN** пайплайн, где шаг серверов не объявлял, объявляет для него сервер
- **THEN** ключ этого шага отличается от записанного в прошлом прогоне, и возобновление его переисполняет

#### Scenario: Пайплайн без объявлений не задет

- **WHEN** ни один уровень пайплайна серверов не объявляет
- **THEN** ключи его шагов совпадают с вычисленными до появления этой возможности
