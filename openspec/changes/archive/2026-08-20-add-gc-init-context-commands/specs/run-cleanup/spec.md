## ADDED Requirements

### Requirement: Уборка без порога возраста только отчитывается

Команда `stepcast gc` SHALL без ключа `--older-than` перечислять прогоны
текущего проекта как кандидатов на удаление вместе с датой завершения и
оценкой занимаемого места, показывать суммарную оценку и завершаться кодом 0,
не удаляя ничего. Вывод MUST называть флаг, которым удаление выполняется.

#### Scenario: Отчёт без действия

- **WHEN** `stepcast gc` вызвана без `--older-than`
- **THEN** команда печатает список прогонов с их размером и итоговую сумму
- **AND** ни один файл прогона не удалён

#### Scenario: Подсказка о флаге удаления

- **WHEN** `stepcast gc` вызвана без `--older-than`
- **THEN** вывод называет `--older-than` как способ выполнить удаление

#### Scenario: Нет прогонов

- **WHEN** у проекта ещё нет ни одного прогона
- **THEN** команда сообщает об этом и завершается кодом 0

### Requirement: Уборка по возрасту удаляет прогоны старше порога

Команда `stepcast gc --older-than <длительность>` SHALL удалять прогоны
текущего проекта, чей возраст превышает указанную длительность, и оставлять
остальные нетронутыми. Возраст прогона SHALL вычисляться от `finished_at` из
его `run.json`; если `finished_at` отсутствует — от `started_at`. Формат
длительности MUST совпадать с форматом `timeout` и `budget.wallclock`.

#### Scenario: Удаление прогонов старше порога

- **WHEN** вызвана `stepcast gc --older-than 30d`, а прогон завершился 40 дней назад
- **THEN** директория этого прогона больше не содержит `workspace/`, `jobs/`, `artifacts/`, `anchors/`, `pipeline.lock.yml` и `events.ndjson`

#### Scenario: Прогоны младше порога не трогаются

- **WHEN** вызвана `stepcast gc --older-than 30d`, а прогон завершился 10 дней назад
- **THEN** его директория остаётся без изменений

#### Scenario: Возраст прерванного прогона

- **WHEN** прогон не содержит `finished_at` в `run.json`
- **THEN** его возраст вычисляется от `started_at`

#### Scenario: Отчёт об удалённом

- **WHEN** уборка по порогу возраста завершилась
- **THEN** вывод перечисляет удалённые прогоны и суммарно освобождённое место

### Requirement: Уборка сохраняет минимум и работает без подтверждения

Уборка SHALL сохранять `run.json`, `status.json` и `usage.json` каждого
удаляемого прогона и удалять остальное содержимое его директории. Команда
MUST NOT запрашивать интерактивное подтверждение: решение об удалении
принимается наличием и значением `--older-than`, а не диалогом в терминале.

#### Scenario: Минимум остаётся

- **WHEN** прогон подвергся уборке
- **THEN** `run.json`, `status.json` и `usage.json` этого прогона читаются как прежде

#### Scenario: Без интерактивного ввода

- **WHEN** `stepcast gc --older-than <длительность>` вызвана в неинтерактивном окружении без доступного stdin
- **THEN** команда выполняет удаление и завершается, не ожидая ввода
