## ADDED Requirements

### Requirement: Просмотр контекста работает без запуска пайплайна

Команда `stepcast context --job <job> --step <step>` SHALL вычислять состав и
размер контекста, который получил бы указанный агентский шаг, не запуская
пайплайн и не обращаясь к агентскому бэкенду. Отчёт MUST показывать
четырёхуровневый разрез — выходы предшественников, уровень пайплайна, уровень
работы, уровень шага — и итоговый размер, тем же способом, каким он
записывается в `context.json` при живом прогоне.

#### Scenario: Отчёт без прогона

- **WHEN** `stepcast context --job implement --step write-code` вызвана без предварительного `stepcast run`
- **THEN** команда печатает отчёт и завершается кодом 0, не создавая директории прогона

#### Scenario: Разрез по уровням

- **WHEN** вычислен отчёт для агентского шага
- **THEN** вывод показывает отдельные величины для выходов предшественников, пайплайна, работы и шага, а также их сумму

#### Scenario: Раскрытие требует объявленных входов

- **WHEN** пайплайн объявляет обязательный вход, не переданный через `--input`
- **THEN** команда завершается той же ошибкой, что дал бы `stepcast lint`, с указанием отсутствующего входа

### Requirement: Просмотр контекста отклоняется для командного шага

Команда `stepcast context` SHALL отказывать, если указанный шаг — `run`, а не
`agent`, с объяснением, что командные шаги не собирают контекст, вместо
показа пустого или нулевого отчёта.

#### Scenario: Командный шаг

- **WHEN** `stepcast context` вызвана с указанием шага типа `run`
- **THEN** команда завершается ошибкой, называющей шаг командным, и не печатает отчёт из нулевых величин

### Requirement: Выходы предшественников оцениваются по последнему прогону

Оценка уровня «выходы предшественников» SHALL браться из `artifacts/<job>.json`
последнего прогона текущего проекта, если такой прогон существует и
предшествующая работа опубликовала выход. Если прогонов ещё не было или
предшественник ничего не публиковал, этот уровень MUST быть помечен как
неизвестный, а не подставлен нулём.

#### Scenario: Оценка по прошлому прогону

- **WHEN** у проекта есть завершённый прогон, где работа-предшественник опубликовала выход
- **THEN** уровень «выходы предшественников» в отчёте содержит оценку размера этого выхода

#### Scenario: Прогонов ещё не было

- **WHEN** у проекта нет ни одного прогона
- **THEN** уровень «выходы предшественников» помечен как неизвестный, а не как нулевой
