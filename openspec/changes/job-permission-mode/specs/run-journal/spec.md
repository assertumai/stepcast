## MODIFIED Requirements

### Requirement: Поток событий

Система SHALL вести журнал событий построчно, по одной записи на событие, в формате, допускающем чтение по мере поступления.
Записи MUST включать начало и завершение работ и шагов, попытки, непройденные
предикаты, исключения по запретам окружения и путей, предупреждения и остановки
по бюджету, обнаружение зависшего шага, отказ бэкенда в разрешении на вызов
инструмента.

Запись об отказе в разрешении MUST называть работу, шаг и имя инструмента, а
деталь отказа MUST сводиться к одной строке по общему правилу обезвреживания
свободного текста — управляющие последовательности сняты, переводы строк
заменены пробелами, длинный хвост обрезан. Полный вход отклонённого вызова
остаётся в логах шага.

#### Scenario: Чтение на лету

- **WHEN** прогон исполняется
- **THEN** содержимое журнала событий доступно для чтения до его завершения

#### Scenario: Запись об исключении по запрету

- **WHEN** переменная окружения или путь контекста исключены по запрету
- **THEN** в журнале есть запись с именем и сработавшим шаблоном

#### Scenario: Запись об отказе в разрешении

- **WHEN** агентский шаг в жёстком режиме прав попытался вызвать инструмент вне своего списка
- **THEN** в журнале есть запись с работой, шагом и именем инструмента

#### Scenario: Деталь отказа обезврежена

- **WHEN** вход отклонённого вызова многострочен или несёт управляющие последовательности
- **THEN** запись события несёт его одной строкой без управляющих последовательностей, а полный текст остаётся в логах шага

## ADDED Requirements

### Requirement: Число отказов в разрешении хранится в записи попытки

Запись попытки агентского шага SHALL нести число отказов в разрешении, случившихся в этой попытке.
Поле MUST быть необязательным: журналы, снятые прежней версией движка, MUST
читаться как прежде, а отсутствие поля MUST пониматься как отсутствие сведений,
а не как ноль отказов.

#### Scenario: Отказы посчитаны

- **WHEN** попытка агентского шага получила два отказа в разрешении
- **THEN** её запись в состоянии прогона несёт число отказов, равное двум

#### Scenario: Журнал прежней формы

- **WHEN** читается запись попытки, снятая до появления поля
- **THEN** она разбирается штатно, а число отказов у неё отсутствует
