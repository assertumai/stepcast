## MODIFIED Requirements

### Requirement: Отдача содержимого ограничена двумя формами адреса

Демон SHALL отдавать выведенное из пути запроса содержимое ровно по объявленным формам адреса и ни по каким иным: `/widgets/<projectKey>/<id>.js`, `/widgets/runtime/<имя>.js`, где `<имя>` принадлежит закрытому перечню модулей-переходников, и `/plugins/<id>.js` — браузерная половина плагина действующего состава. Сегменты адреса виджета MUST проверяться как безопасные сегменты пути, итоговый путь файла MUST оставаться внутри каталога виджетов проекта после приведения к реальному пути, и расширение исходника MUST быть фиксированным. Сегмент адреса плагина MUST проверяться так же, отдаваемое MUST собираться только из файлов внутри каталога этого плагина после приведения к реальному пути, и отдаваться MUST только половина плагина, названного действующим составом. Любой другой путь под `/widgets/` и под `/plugins/` SHALL давать 404, а перечисления содержимого каталога демон MUST NOT отдавать ни под каким адресом.

#### Scenario: Шаг вверх по дереву

- **WHEN** запрошен виджет, чей идентификатор содержит `..` или разделитель пути
- **THEN** запрос отклонён, файл не отдан

#### Scenario: Абсолютный путь в адресе

- **WHEN** запрошен виджет, чей идентификатор выглядит абсолютным путём
- **THEN** запрос отклонён, файл не отдан

#### Scenario: Символическая ссылка из каталога виджетов наружу

- **WHEN** в каталоге виджетов лежит символическая ссылка `escape.tsx` на файл вне этого каталога, и она запрошена
- **THEN** запрос отклонён, содержимое файла за пределами каталога не отдано

#### Scenario: Путь под /widgets сверх объявленных форм

- **WHEN** запрошен путь под `/widgets/`, не совпадающий ни с формой виджета, ни с формой переходника
- **THEN** ответ 404, и содержимое каталога не перечислено

#### Scenario: Небезопасный сегмент в адресе плагина

- **WHEN** запрошена половина плагина, чей идентификатор содержит `..` или разделитель пути
- **THEN** ответ 404, и ничего не собирается и не отдаётся

#### Scenario: Путь под /plugins сверх объявленной формы

- **WHEN** запрошен путь под `/plugins/`, не совпадающий с формой браузерной половины
- **THEN** ответ 404, и содержимое каталога плагинов не перечислено
