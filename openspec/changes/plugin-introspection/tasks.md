## 2. Модель осмотра серверной половины

- [x] 2.1 `src/core/plugins/introspect.ts`: тип `Introspection` — `version`, `surface`, `rows[]` (место, `id`, `use`, слой, состояние с причиной, плагин с версией, вклады по видам, объявленные и запрошенные сервисы), `browser` (Решение 1) — плюс два поля сверх записанного: `builtin` (вклады и сервисы корневой области вне окон строк, 2.3) и `attribution` (названная причина, когда итоги строк пришли без областей), и `isIntrospection` для разбора чужого осмотра (3.4)
- [x] 2.2 Приписывание по области: вклады и сервисы фибера строки — этой строке (Решение 2, первое правило); итог, заменённый на отказ о незакрытом внедрении, сохраняет область, а там, где загрузчик её снимает, — снимок запрошенных имён (`RowOutcome.requestedServices`), иначе неразрешённое имя жило бы только в тексте причины
- [x] 2.3 Приписывание корневых регистраций: `RowOutcome` (или соседняя запись загрузчика) несёт то, что появилось за время применения встроенной строки движка; поздний вклад корневой области остаётся за встроенным владельцем (Решение 2, второе правило и его граница) — реализовано `RowOutcome.rootWindow` (снимок «до/после» вокруг `BuiltinRow.apply`, `load.ts`), а не отдельным полем `RowOutcome`; вклады корневой области вне всяких окон (команды CLI и виды шага ядра из `createKernelShell`, поздняя регистрация) собраны полем `Introspection.builtin` и печатаются разделом «встроенный (вне строк дерева)»
- [x] 2.4 `RowOutcome` несёт фибер применённой строки (`RowOutcome.fiber`) — тем же местом, где загрузчик уже ведёт `declaredBy`; `BuiltinRow.apply` (`builtin.ts`) и `screenRow` (`src/ui/screens/registry.ts`) возвращают свою область, а не `void`
- [x] 2.5 `inspectPluginTree` собирает осмотр до `kernel.dispose()` и возвращает его вместе с итогами (Решение 15) — реализовано полем `introspection` в возвращаемом объекте `{ outcomes, introspection }`, а не отдельным вызовом
- [x] 2.6 Тесты (`test/plugins-introspect.test.ts`, `test/plugins-command.test.ts`): вклад плагинной строки, вклад встроенной строки движка, замена встроенной строки меняет автора, объявленный сервис у объявившего, незакрытое внедрение видно неразрешённым именем, отключённая строка без вкладов
