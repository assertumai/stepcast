## ADDED Requirements

### Requirement: Состав виджетов несёт признак устаревания и его причину

Состав виджетов, который демон отдаёт витрине потоком событий, SHALL нести у каждого виджета признак устаревания и причину — имя, которого действующая таблица общих модулей больше не несёт, вместе с текстом записи о смене, если он есть. Признак MUST меняться тем же тактом наблюдателя и тем же правилом отличия, каким меняется версия виджета: правка файла виджета, снявшая ушедшее имя, MUST снимать и признак. Признак MUST не отменять отдачу виджета: устаревший виджет по-прежнему компилируется и отдаётся, а отказ, если он случится, остаётся отказом браузера.

#### Scenario: Устаревший виджет назван в составе

- **WHEN** виджет проекта импортирует имя, которого таблица не несёт
- **THEN** состав виджетов несёт у него признак устаревания и причину с этим именем

#### Scenario: Правка снимает признак

- **WHEN** файл виджета исправлен и ушедшего имени больше не импортирует
- **THEN** следующий такт наблюдателя отдаёт состав без признака устаревания у этого виджета

### Requirement: Экран виджетов показывает причину устаревания и предлагает миграцию

Экран «Виджеты» SHALL показывать у устаревшего виджета причину — имя, которого таблица больше не несёт, — и действие, запускающее пайплайн миграции для этого проекта. Действие MUST запускать прогон тем же маршрутом запуска, каким витрина запускает пайплайн проекта, и MUST подтверждать приём запуска, а не обещать результат: появившийся прогон виден обычным тактом обзора, а предложенные им правки — в очереди предложений. Проект без устаревших виджетов MUST этого действия не показывать.

#### Scenario: Кнопка миграции у устаревшего виджета

- **WHEN** экран показывает виджет с признаком устаревания
- **THEN** рядом видна причина и действие «мигрировать», запускающее пайплайн миграции этого проекта

#### Scenario: Запуск подтверждается, а не обещает результат

- **WHEN** человек нажал действие миграции
- **THEN** витрина подтверждает приём запуска, прогон появляется в обзоре обычным тактом, а его предложения — в очереди

#### Scenario: Устаревших виджетов нет

- **WHEN** ни один виджет проекта не устарел
- **THEN** действия миграции на экране нет
