## ADDED Requirements

### Requirement: Проекты-призраки вычёркиваются при старте демона

Демон при старте MUST вычеркнуть каждый проект указателя `projects.json`,
чей путь больше не существует на диске: запись указателя, каталог прогонов
и записи хранилища расхода. Проект без пути в указателе MUST остаться.

#### Scenario: Проект из временного каталога

- **WHEN** в `projects.json` есть запись с путём `/var/folders/.../eval-xyz`, которого нет на диске
- **THEN** после старта демона записи нет, каталога `<runsRoot>/<key>` нет, записей расхода этого проекта нет, а проект с существующим путём и каталог без записи не тронуты
