## 7. За человеком, вне `project.edit_paths`

Границы правок (`.stepcast/config.yml`, `project.edit_paths`) не включают
`.stepcast/**`: правки ниже вносит человек. Механизм ими не меняется — агент
по-прежнему отдаёт только пути, а закрепление подставляет движок, — меняется
слово «ревизия».

- [ ] 7.1 `.stepcast/prompts/remember.md`, абзац «Файлы памяти не правь»: «ревизию якоря он подставляет сам» → «закрепление якоря — дайджест его содержимого — он подставляет сам».
- [ ] 7.2 Там же, строка под примером JSON: «`anchors` — только пути, без ревизий: ревизию подставит движок.» → «`anchors` — только пути: закрепление подставит движок.»
- [ ] 7.3 `.stepcast/prompts/knowledge-rules.md`, пункт про `anchors`: «Ревизию подставляет движок: объявлять себя вечно свежим пишущий не вправе.» → «Закрепление — дайджест содержимого пути — подставляет движок: объявлять себя вечно свежим пишущий не вправе.»
- [ ] 7.4 `.stepcast/jobs/remember.yml`, шапка-комментарий: «ревизию якоря подставляет движок, а не пишущий. Правь агент файл напрямую — он писал бы якорь без ревизии, устаревание по такому якорю не считается вовсе» → то же про закрепление; смысл абзаца сохранить целиком, заменив только предмет подстановки.
