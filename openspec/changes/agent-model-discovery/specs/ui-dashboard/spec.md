## ADDED Requirements

### Requirement: Страница «Агенты» выбирает модель из распознанного списка

Страница «Агенты» SHALL предлагать выбор из распознанного списка моделей для модели по умолчанию и для каждого из пяти tier'ов агента.
Список MUST принадлежать тому агенту, в чьей карточке он показан: список
одного агента MUST NOT предлагаться в карточке другого. Рядом со списком MUST
быть сказано, откуда он взят и что он — подсказка, а не перечень допустимого.
Ручной ввод имени MUST оставаться доступен и при распознанном списке. Пустое
значение MUST по-прежнему снимать переопределение.

#### Scenario: Выбор из списка

- **WHEN** список моделей агента распознан, и пользователь правит модель по умолчанию или модель tier'а
- **THEN** значения этого списка предложены выбором, а выбранное сохраняется в глобальный файл настроек

#### Scenario: У каждого агента свой список

- **WHEN** на странице показаны карточки двух агентов с разными распознанными списками
- **THEN** каждая карточка предлагает список своего агента

#### Scenario: Ручной ввод при распознанном списке

- **WHEN** нужная модель в распознанном списке отсутствует
- **THEN** пользователь вводит её имя вручную, и оно сохраняется

#### Scenario: Пустое значение снимает переопределение

- **WHEN** пользователь очищает поле модели
- **THEN** переопределение снимается, как и до появления списка

### Requirement: Сохранённое имя вне списка не теряется и видно как внесписочное

Страница «Агенты» SHALL показывать уже сохранённое имя модели, даже если распознанный список его не содержит, и MUST помечать его как значение вне списка.
Открытие страницы, выбор другого агента и сохранение правки в соседнем поле
MUST NOT изменять и MUST NOT очищать такое значение. Пометка MUST отличать
«имени нет в списке» от «имя неверно»: список неполон, и внесписочное значение
не является ошибкой.

#### Scenario: Имя вне списка показано и помечено

- **WHEN** в настройках сохранено имя модели, которого нет в распознанном списке агента
- **THEN** страница показывает это имя выбранным и помечает его как значение вне списка

#### Scenario: Сохранение соседнего поля не трогает внесписочное значение

- **WHEN** пользователь правит модель одного tier'а и сохраняет, а модель по умолчанию того же агента внесписочна
- **THEN** после сохранения модель по умолчанию остаётся прежней

### Requirement: Недоступность распознавания не ломает страницу «Агенты»

Страница «Агенты» SHALL отрисовываться и позволять правку, когда распознавание списка моделей недоступно.
Отрисовка MUST NOT дожидаться ответа проб: настройки показываются сразу, а
списки появляются по мере готовности. Причина недоступности MUST называться
словами в карточке того агента, к которому относится, — агент не установлен,
не ответил за отпущенное время, ответил отказом, ответил неразбираемым
выводом, распознавание сорвалось, перечислять модели не умеет. Текст, сказанный
CLI, MUST идти при подписи, называющей причину, а его отсутствие MUST NOT
оставлять карточку без слов о причине вовсе. Прежний способ задать имя вручную
MUST оставаться, и правка прочих полей карточки MUST оставаться доступной.
Недоступность распознавания одного агента MUST NOT скрывать списки остальных.
Страница MUST давать потребовать распознавание заново, не перезапуская демон.

#### Scenario: Агент не установлен

- **WHEN** команда агента отсутствует на машине демона
- **THEN** карточка говорит, что команду не удалось запустить, и оставляет ручной ввод имени модели

#### Scenario: Агент не ответил

- **WHEN** проба перечисления не завершилась за отпущенное время
- **THEN** карточка говорит об этом, а страница остаётся работоспособной

#### Scenario: Агент перечислять не умеет

- **WHEN** бэкенд не объявляет перечисления моделей
- **THEN** карточка говорит, что список для этого агента не распознаётся, и предлагает ввод имени вручную

#### Scenario: Страница показана до ответа проб

- **WHEN** пользователь открывает страницу, а пробы ещё не завершились
- **THEN** настройки уже показаны, а поля моделей говорят, что список распознаётся

#### Scenario: Отказ у одного агента

- **WHEN** распознавание не удалось у одного агента и удалось у другого
- **THEN** второй агент показывает свой список, а первый — причину отказа

#### Scenario: Причину починили

- **WHEN** пользователь устранил причину отказа — установил агента, поправил его команду, обновил аутентификацию — и потребовал распознать заново
- **THEN** страница перечисляет модели заново, а не показывает удержанный демоном прежний отказ

### Requirement: Имя модели копируется в буфер одной кнопкой

Страница «Агенты» SHALL давать скопировать имя модели в буфер обмена кнопкой рядом с каждым полем модели — модели по умолчанию и каждого из пяти tier'ов.
Копироваться MUST именно имя модели — то, что вставляется в `model:` пайплайна
или работы, — без пояснений и без имени tier'а. Неудача копирования MUST быть
сказана рядом с кнопкой, а не проглочена, и значение MUST оставаться
выделяемым текстом, чтобы его можно было скопировать вручную. Кнопка MUST NOT
менять сохранённое значение.

#### Scenario: Копирование имени

- **WHEN** пользователь нажимает кнопку копирования у поля модели
- **THEN** в буфере обмена оказывается имя модели, и страница подтверждает это

#### Scenario: Буфер обмена недоступен

- **WHEN** браузер отказал в доступе к буферу обмена
- **THEN** страница говорит об отказе рядом с кнопкой, а значение остаётся видимым и выделяемым

#### Scenario: Копирование не изменяет настройки

- **WHEN** пользователь копирует имя модели и уходит со страницы, не сохраняя
- **THEN** настройки остаются прежними
