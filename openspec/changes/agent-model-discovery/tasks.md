## 8. Приёмка

- [x] 8.1 `npm run check` — зелёный целиком.
- [x] 8.2 Живая проверка — не браузером `stepcast up` (в песочнице этого прогона фоновый демон и прямой запуск CLI отклоняются политикой, см. `test/fixtures/models/README.md`), а тем же кодом демона (`createUiServer`) прямым обращением к `/api/settings` и `/api/models`. Прогнаны все три записи: установленный настоящий `claude` (список — `fable, opus, sonnet, claude-fable-5`, ровно фикстура), `backends.claude.command`, указывающая на несуществующий файл (`not_installed` с именем команды), и скрипт-заглушка со сном (`/api/settings` ответил за 1 мс, не дождавшись пробы). Внесписочное сохранённое имя (`заведомо-вне-списка`) осталось в `/api/settings` как есть. Отрисовку страницы браузером и клик по кнопке копирования эта песочница проверить не даёт — это осталось на совести `npm run typecheck:ui` и код-ревью.
- [ ] 8.3 `openspec validate "agent-model-discovery" --strict` — команда `openspec` отклоняется политикой песочницы («This command requires approval») на любом вызове, включая `openspec --help`, и в сессии реализации, и в сессии правок по ревью; выполнить и подтвердить зелёным результат отсюда нельзя. Расхождения с `design.md`, найденные по ходу, дописаны решениями «по ходу реализации» (10 — codex, 11–14 — правки по ревью).
