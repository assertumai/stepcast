## ADDED Requirements

### Requirement: Каталог вызова предиката script

Каждый вызов предиката `script` SHALL оставлять в каталоге шага подкаталог
`script-<n>`, где `<n>` — сквозной порядковый номер вызова внутри этого шага,
начиная с 1, — тем же образом, что и `judge-<n>` у предиката `judge`. Счётчик
MUST расти через попытки и через несколько предикатов `script` одного шага, не
начинаясь заново на каждой попытке.

Подкаталог MUST содержать `input.json`, переданный вызову, `stdout.log` и
`stderr.log` самого процесса и MAY содержать `output.json`, если раннер его
записал. Все файлы подкаталога MUST быть обычным содержимым каталога шага:
уборка вправе удалить их наравне с логами шага.

#### Scenario: Один предикат, три попытки

- **WHEN** шаг с одним предикатом `script` прошёл три попытки
- **THEN** каталог шага содержит `script-1`, `script-2`, `script-3`

#### Scenario: Несколько предикатов в одной попытке

- **WHEN** шаг объявляет два предиката `script` в одной попытке
- **THEN** каталог шага содержит `script-1` и `script-2` для этой попытки, с общей сквозной нумерацией на весь шаг

#### Scenario: Состав подкаталога

- **WHEN** предикат `script` вычислен
- **THEN** его подкаталог содержит `input.json`, `stdout.log` и `stderr.log`

#### Scenario: Скрипт записал причину отказа

- **WHEN** предикат не прошёл и записал `output.json` с полем `reason`
- **THEN** этот файл лежит в его подкаталоге рядом с `input.json` и логами
