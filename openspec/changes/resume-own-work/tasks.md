## 7. Тесты

- [x] 7.1 Прогон, оборванный на последней работе, при возобновлении
      переиспользует все предыдущие работы, когда дерево изменено только его
      собственным выводом
- [x] 7.2 Изменение пути, произведённого шагом позже судимого, не
      инвалидирует судимый шаг; изменение пути, произведённого шагом раньше,
      инвалидирует
- [x] 7.3 Чужая правка внутри области входов работы инвалидирует её шаги и
      названа в причине; правка результата успешного шага переисполняет его
- [x] 7.4 Правка файла одной работы переисполняет только её шаги и не задевает
      остальные; причина называет изменение определения
- [x] 7.5 Наблюдённые входы записи сужают область при отпечатке по всему
      дереву; объявленные `inputs` работы имеют приоритет
- [x] 7.6 `--from <работа>` переиспользует верх графа при изменённом дереве,
      перечисляет проигнорированные правки и не переиспользует шаг с
      изменившимся определением
- [x] 7.7 Отчёт `--dry-run` содержит вердикт по каждой работе, включая
      частичное переисполнение, и не создаёт прогона и не трогает дерево
- [x] 7.8 Выход переиспользованной работы лежит в `artifacts/` нового прогона
      и разрешается через `${jobs.<id>.output.*}`; работа с невосстановимым
      выходом переисполняется
- [x] 7.9 `output.from` при частичном переиспользовании работы публикует выход
      переиспользованного шага
