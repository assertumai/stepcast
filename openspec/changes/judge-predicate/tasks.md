## 1. Вычислитель судьи

- [x] 1.1 Схема вердикта `{ pass: boolean, reason: string }` поставляется со stepcast и передаётся бэкенду как схема структурированного вывода
- [x] 1.2 Вызов судьи: свежая сессия, бэкенд и модель из предиката либо из умолчаний, политика доступа шага не передаётся
- [x] 1.3 Промпт судьи собирается из утверждения, задания шага, текстового и структурированного вывода и результатов остальных предикатов; контекст шага в него не входит
- [x] 1.4 Разбор ответа: только структура по схеме; отсутствие вердикта, неразобранный ответ и прерывание по времени дают непройденный предикат с называющей причину подробностью
- [x] 1.5 Вызов ограничен `timeout` шага и наблюдается общим детектором тишины

## 2. Встраивание в попытку

- [x] 2.1 Синхронный проход предикатов помечает `judge` невычисленным вместо отказа «не реализовано»
- [x] 2.2 Асинхронный второй проход вызывает судей по очереди и подставляет результаты на объявленные места в `expect.json`
- [x] 2.3 Второй проход общий для агентского и командного шага; на командном шаге место структурированного вывода занимает stdout
- [x] 2.4 Судья не вызывается, если в попытке уже не прошёл жёсткий предикат, вычисляемый без обращения к агенту; результат записывается невычисленным
- [x] 2.5 Совещательный вердикт статус попытки не меняет; жёсткий отклоняет попытку
- [x] 2.6 Причина непройденного вердикта входит в разбор прошлой неудачи при `include_failure`

## 3. Расход, бюджет и журнал

- [x] 3.1 Расход судьи сливается с расходом попытки и учитывается областями шага, работы и прогона
- [x] 3.2 Исчерпанный бюджет судью не начинает: результат невычислен; превышение после вызова останавливает шаг со статусом `budget_exceeded`
- [x] 3.3 Каталог `judge-<n>` со сквозной нумерацией внутри шага: промпт, поток, вердикт, расход, номер попытки и проверявшееся утверждение

## 4. Линт

- [x] 4.1 Отказ «Предикат judge ещё не реализован» снят
- [x] 4.2 Ошибка на неизвестный бэкенд судьи
- [x] 4.3 Ошибка на бэкенд судьи без поддержки структурированного вывода
- [x] 4.4 Предупреждение о шаге без структурных предикатов продолжает срабатывать на шаге с одним совещательным судьёй

## 5. Тесты

- [x] 5.1 Жёсткий вердикт `pass: false` отклоняет попытку, `pass: true` — проходит
- [x] 5.2 Совещательный вердикт `pass: false` попытку не отклоняет и записан с признаком совещательного
- [x] 5.3 Ответ без структуры и ответ не по схеме дают непройденный предикат с внятной причиной
- [x] 5.4 Судья не вызывается после непройденного жёсткого структурного предиката; после непройденного совещательного — вызывается
- [x] 5.5 Сессия судьи не связана с сессией шага
- [x] 5.6 Промпт судьи не содержит контекста шага и содержит результаты остальных предикатов
- [x] 5.7 Каталог `judge-<n>` создан, пронумерован сквозным образом и содержит обещанное
- [x] 5.8 Расход судьи виден в расходе попытки и приводит к `budget_exceeded` при превышении потолка шага
- [x] 5.9 Судья на шаге командной строки получает stdout
- [x] 5.10 Линт: `judge` не отклоняется; неизвестный бэкенд судьи и бэкенд без структурированного вывода отклоняются
- [x] 5.11 `npm run check` проходит
