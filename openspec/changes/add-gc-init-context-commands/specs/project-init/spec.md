## ADDED Requirements

### Requirement: Инициализация создаёт рабочий пайплайн без внешних зависимостей

Команда `stepcast init` SHALL создавать в текущем каталоге файл `stepcast.yml`
по минимальному шаблону и отдельный файл работы, подключаемый через `uses`.
Шаблон MUST исполняться командой `stepcast run` без агентского бэкенда и без
сетевого доступа: работа шаблона MUST состоять из шага `run`.

#### Scenario: Файлы созданы

- **WHEN** `stepcast init` вызвана в пустом каталоге
- **THEN** появляется `stepcast.yml` и отдельный файл работы, на который он ссылается через `uses`

#### Scenario: Шаблон проходит статическую проверку

- **WHEN** созданный `stepcast.yml` проверен командой `stepcast lint`
- **THEN** линт не сообщает ни одной ошибки

#### Scenario: Шаблон исполняется

- **WHEN** созданный `stepcast.yml` запущен командой `stepcast run` без настроенного агентского бэкенда
- **THEN** прогон завершается успехом

### Requirement: Инициализация не перезаписывает существующий пайплайн без согласия

Команда `stepcast init` SHALL отказываться создавать `stepcast.yml`, если файл
с таким именем уже существует в текущем каталоге, если не передан флаг
`--force`.

#### Scenario: Отказ без флага

- **WHEN** `stepcast init` вызвана в каталоге, где `stepcast.yml` уже существует, без `--force`
- **THEN** команда завершается ошибкой конфигурации, а существующий файл не изменён

#### Scenario: Перезапись с флагом

- **WHEN** `stepcast init --force` вызвана в каталоге, где `stepcast.yml` уже существует
- **THEN** файл заменяется шаблоном
