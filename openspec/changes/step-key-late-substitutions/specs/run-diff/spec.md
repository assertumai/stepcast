## MODIFIED Requirements

### Requirement: Сравнение прогонов по ключам шагов

Команда `stepcast diff <run-a> <run-b>` SHALL сопоставлять шаги двух прогонов по паре идентификаторов работы и шага и относить каждый к одной из категорий: совпавший по ключу, различающийся по ключу, присутствующий только в одном из прогонов. Порядок вывода MUST повторять порядок исполнения, а не порядок обнаружения различий. Различие, объясняемое только тем, что прогоны — разные прогоны, MUST NOT попадать в вывод: шаги работы с отложенными подстановками пространства `run` MUST относиться к совпавшим, если их определение, входы и выходы предшественников не различались.

#### Scenario: Идентичные прогоны

- **WHEN** сравниваются два прогона, все шаги которых совпали по ключам
- **THEN** вывод сообщает об отсутствии различий, а команда завершается кодом 0

#### Scenario: Два прогона работы с подстановкой директории прогона

- **WHEN** сравниваются два прогона одной неизменной работы, подключающей контекстом `${run.dir}/item.json`
- **THEN** её шаги отнесены к совпавшим, а не к различающимся

#### Scenario: Шаг изменился

- **WHEN** ключ шага различается между прогонами
- **THEN** шаг отнесён к различающимся

#### Scenario: Шаг есть только в одном прогоне

- **WHEN** работа второго прогона содержит шаг, отсутствующий в первом
- **THEN** шаг отнесён к присутствующим только во втором прогоне

#### Scenario: Порядок вывода

- **WHEN** различаются шаги из разных работ
- **THEN** они выведены в порядке исполнения работ и шагов внутри них
