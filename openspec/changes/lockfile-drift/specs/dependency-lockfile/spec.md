## ADDED Requirements

### Requirement: Синхронность package-lock.json с package.json проверяется в npm run check

`npm run check` SHALL завершаться отказом, если для какого-либо поля зависимостей (`dependencies`, `devDependencies`, `optionalDependencies`) объявленный в `package.json` диапазон версии расходится с диапазоном той же зависимости в корневой записи `package-lock.json` (`packages[""]`).

Сверка воспроизводит ту же проверку, что `npm ci` делает перед установкой,
объявляя дерево несинхронным. Дорожки петли поднимаются через `npm install`,
который такое расхождение тихо чинит вместо того, чтобы его показать, — без
собственной проверки в `npm run check` дрейф остаётся незамеченным до
случайного `npm ci` в чистом рабочем дереве.

#### Scenario: Диапазон зависимости разошёлся

- **WHEN** `package.json` объявляет для зависимости диапазон версии, отличный от диапазона той же зависимости в корневой записи `package-lock.json`
- **THEN** `npm run check` завершается ненулевым кодом и называет разошедшуюся зависимость

#### Scenario: Диапазоны совпадают

- **WHEN** для каждой зависимости диапазон версии в `package.json` и в корневой записи `package-lock.json` совпадает
- **THEN** эта проверка проходит и не препятствует зелёному `npm run check`
