## 2. Выбор способа передачи для склеенной записи

- [x] 2.1 Ввести силу объявления: явный `inline` (2) сильнее вставки, полученной из `auto` по порогу (1), а вставка сильнее передачи путём (0); силу повторного объявления считать по уже известным `tokens` первой записи, а не по новому чтению файла
- [x] 2.2 Обновлять `mode` и `pinned` склеенной записи только тогда, когда повторное объявление строго сильнее: при равной силе исход совпадает с первым объявлением, поэтому порядок обхода уровней на результат не влияет
- [x] 2.3 Тесты: `reference` на пайплайне и `inline` на работе дают вставку; `inline` на пайплайне и `reference` на шаге оставляют вставку; два `auto` дают тот же исход, что одно `auto`; `inline` с любого уровня делает запись непонижаемой при превышении предела
- [x] 2.4 Тест закрепления проверяет именно закрепление: крупный файл (`auto` сверх порога на пайплайне, `inline` на работе) отказывает без единого понижения, а понижаемая пара без `inline` тот же предел проходит понижением
