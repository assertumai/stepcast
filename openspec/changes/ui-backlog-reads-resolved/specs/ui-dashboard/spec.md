## ADDED Requirements

### Requirement: Экран очереди показывает и открытые, и решённые пункты проекта

Экран очереди SHALL читать у каждого проекта, видимого в обзоре, оба файла — `backlog.md` и `resolved.md` — и SHALL показывать их пункты одним объединённым списком раздела проекта, под теми же фильтрами и плановым порядком, какими показан раздел с одним файлом. Список MUST быть конкатенацией: сперва пункты `backlog.md` в его собственном порядке, затем пункты `resolved.md` в его собственном порядке. По каждому пункту экран MUST показывать имя файла-источника. Отсутствие файла `resolved.md` MUST NOT считаться ошибкой — так же, как отсутствие `backlog.md` уже не считается ею.

#### Scenario: Пункты обоих файлов на одном экране

- **WHEN** у проекта есть и `backlog.md`, и `resolved.md`, у каждого — свои пункты
- **THEN** раздел проекта показывает пункты обоих файлов одним списком, и у каждого пункта виден его файл-источник

#### Scenario: Порядок внутри объединённого списка

- **WHEN** у проекта есть оба файла
- **THEN** пункты `backlog.md` идут первыми в своём файловом порядке, за ними — пункты `resolved.md` в своём файловом порядке

#### Scenario: Файл resolved.md отсутствует

- **WHEN** у проекта есть `backlog.md`, а `resolved.md` нет вовсе
- **THEN** раздел проекта показывает пункты `backlog.md` и не считается ошибкой из-за отсутствия `resolved.md`

#### Scenario: Оба файла отсутствуют

- **WHEN** у проекта нет ни `backlog.md`, ни `resolved.md`
- **THEN** экран не показывает раздела этого проекта, как и раньше в отсутствие `backlog.md`

### Requirement: Отказ разбора одного файла очереди не скрывает пункты другого

Раздел проекта SHALL показывать отказ разбора каждого файла — `backlog.md` и `resolved.md` — независимо друг от друга: отказ одного файла MUST NOT скрывать пункты, успешно разобранные из другого. Каждый отказ MUST показываться с именем отказавшего файла, тем же составом полей (текст отказа, файл, место внутри документа), каким раздел уже показывает единственный отказ сегодня.

#### Scenario: Resolved.md не разбирается, backlog.md исправен

- **WHEN** `backlog.md` проекта разбирается, а `resolved.md` содержит строку, не разбираемую по формату
- **THEN** раздел проекта показывает пункты `backlog.md` и отдельно — отказ разбора, названный по имени `resolved.md`

#### Scenario: Backlog.md не разбирается, resolved.md исправен

- **WHEN** `resolved.md` проекта разбирается, а `backlog.md` не разбирается
- **THEN** раздел проекта показывает пункты `resolved.md` и отдельно — отказ разбора, названный по имени `backlog.md`

#### Scenario: Оба файла не разбираются

- **WHEN** ни `backlog.md`, ни `resolved.md` проекта не разбираются
- **THEN** раздел проекта показывает два отказа, каждый со своим именем файла, и ни один пункт не показан
