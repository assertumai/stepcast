## MODIFIED Requirements

### Requirement: Таблица раннеров объявляется секцией runners

Конфигурация SHALL содержать секцию `runners` — записи вида «имя → argv-префикс `command`, необязательный список расширений `extensions` и необязательная обёртка `wrapper`», пополняемые и глобальным, и проектным конфигом.

Встроенный слой MUST поставлять записи `node` (`.js`, `.mjs`, `.cjs`),
`node-ts` (`.ts`, `.mts`, с `--experimental-strip-types`), `python3` (`.py`) и
`sh` (`.sh`) — на тех же правах, что прочие встроенные умолчания, с
происхождением «встроенное умолчание» в `stepcast config`. Записи `node` и
`node-ts` MUST объявлять `wrapper` поставляемой пакетом обёрткой шага. Имя
записи MUST состоять из букв, цифр, дефиса и подчёркивания; `command`,
названный слоем, MUST быть непустым списком непустых строк — строковой формы у
него нет, потому что правил разбиения строки на слова у движка нет; каждое
расширение MUST начинаться с точки. Слои MUST сливаться по листьям, как
`backends`, в обе стороны: запись вправе назвать одни `extensions`, один
`command` либо один `wrapper`, перекрывая одноимённую поле за полем, а не
отменяя её целиком. Запись, действующая после слияния всех слоёв, `command`
иметь MUST: раннер, ни в одном слое её не назвавший, — отказ разбора
конфигурации с его именем, потому что пустая команда дала бы argv из одного
пути скрипта, то есть запуск файла напрямую.

Значение `wrapper` MUST принимать три формы: `stepcast:<имя>` — файл,
поставляемый пакетом; путь — по тем же правилам, что значение `script`
(слоями для голого имени, от файла объявления для `./` и `../`); `none` —
обёртки у раннера нет. Незнакомое имя формы `stepcast:<имя>` MUST давать отказ
разбора конфигурации с перечнем поставляемых. Значение `none` MUST быть
единственным способом снять обёртку, унаследованную от встроенного слоя:
слияние по листьям удалять поля не умеет, и переопределённая `command` без
этого тащила бы за собой чужую обёртку.

Отчёт `stepcast config` MUST печатать действующие `command`, `extensions` и
`wrapper` записи значениями, а не их количеством: это единственный отчёт,
отвечающий на вопрос «чем исполнится файл этого расширения» и показывающий,
какой слой перехватил расширение.

Секция MUST быть допустима в обоих конфигах: в отличие от команды бэкенда,
раннер — обычно имя в `PATH`, и зависимость репозитория от него принадлежит
репозиторию.

#### Scenario: Встроенная таблица есть без всякой конфигурации

- **WHEN** ни один файл конфигурации секции `runners` не содержит
- **THEN** действующая таблица содержит `node`, `node-ts`, `python3` и `sh`, и `stepcast config` называет их источником встроенное умолчание

#### Scenario: Встроенные раннеры Node несут обёртку

- **WHEN** напечатан `stepcast config` без всякой пользовательской конфигурации
- **THEN** записи `node` и `node-ts` называют поставляемую пакетом обёртку, а `python3` и `sh` обёртки не имеют

#### Scenario: Проект пополняет таблицу

- **WHEN** проектный конфиг объявляет `runners.uv.command: [uv, run, --script]`
- **THEN** действующая таблица содержит и встроенные записи, и `uv`, а происхождение `uv` называет файл проектного конфига

#### Scenario: Слияние по листьям

- **WHEN** домашний конфиг объявляет только `runners.python3.command: [python3.12]`
- **THEN** запись `python3` сохраняет встроенный список расширений и получает новую команду

#### Scenario: Слияние по листьям в обратную сторону

- **WHEN** домашний конфиг объявляет только `runners.python3.extensions: ['.py', '.py3']`
- **THEN** запись `python3` сохраняет встроенную команду и закрепляет за собой оба расширения

#### Scenario: Обёртка снимается значением none

- **WHEN** проектный конфиг объявляет `runners.node.command: [bun]` и `runners.node.wrapper: none`
- **THEN** действующая запись `node` обёртки не имеет, и argv шага состоит из команды, пути скрипта и его аргументов

#### Scenario: Своя обёртка у своего раннера

- **WHEN** конфиг объявляет `runners.deno.wrapper: ./tools/deno-step.ts`
- **THEN** путь разрешается тем же правилом, что значение `script`, и попадает в argv между командой раннера и путём скрипта

#### Scenario: Неизвестная поставляемая обёртка

- **WHEN** конфиг объявляет `wrapper: stepcast:нет-такой`
- **THEN** разбор конфигурации отказывает, называя ключ и перечень поставляемых обёрток

#### Scenario: Запись без команды

- **WHEN** ни один слой не назвал `command` объявленного раннера
- **THEN** разбор конфигурации отказывает, называя раннер и ключ `command`

#### Scenario: Форма записи проверяется

- **WHEN** конфигурация объявляет `runners.uv.command: "uv run"` либо расширение без точки
- **THEN** разбор конфигурации отклоняет значение, называя файл и ключ

#### Scenario: Отчёт называет команду и расширения

- **WHEN** проектный конфиг объявил `runners.uv` с расширением `.py`, и напечатан `stepcast config`
- **THEN** отчёт показывает команду `uv` и её расширения значениями, называя рядом слой, который их дал
