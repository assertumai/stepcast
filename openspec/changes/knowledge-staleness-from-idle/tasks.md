## 6. За человеком: файлы петли вне `project.edit_paths`

Границы правок не включают `.stepcast/**`, и заход петли этих файлов
коснуться не вправе. Текст приведён целиком, чтобы применение было
механическим.

- [ ] 6.1 `.stepcast/jobs/merge.yml` — добавить вторым шагом датирование расхождений и его коммит:

```yaml
  # Датирование расхождений памяти: ставит момент обнаружения тем, у кого его
  # ещё нет, и снимает у разрешённых. Здесь, а не в дорожке: две дорожки
  # вписали бы дату в одну и ту же строку одного файла, и наложение второй
  # дало бы конфликт, стоивший заходу её работы целиком (та же причина, по
  # которой здесь же стоит слияние единиц). Коммитит за собой: незакоммиченная
  # правка остановила бы следующий заход на проверке чистоты дерева.
  #
  # Гейтом не является — код возврата check отражает состояние памяти, а
  # останов за него уже сделан проверкой внутри дорожки, — поэтому исход
  # команды здесь намеренно проглатывается, а шаг проваливается только на
  # неудаче коммита.
  - id: record-drift
    run: >
      sh -c '"$STEPCAST_BIN" knowledge check --record || true;
      git add -A knowledge &&
      { git diff --cached --quiet ||
        git commit -m "knowledge: датировать обнаруженные расхождения"; }'
    timeout: 5m
    expect: [{ exit_code: 0 }]
```
