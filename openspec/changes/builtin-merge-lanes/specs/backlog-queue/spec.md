## ADDED Requirements

### Requirement: Очередь правится одним кодом

Всякая запись файла очереди — `pick`, `finish`, `settle`, сведение дорожек — SHALL идти через общий модуль ядра и SHALL сохранять исходный режим доступа файла.

Атомарная подмена файла переименованием временного отдаёт очереди режим
временного файла (`0o600`), поэтому режим MUST восстанавливаться после каждой
записи. Проставление исхода MUST быть одной операцией этого модуля: пункт с
уже проставленным `done` либо `failed` не переписывается, а причина сводится
к одной строке — расхождение копий этих правил уже приводило к тому, что
часть записей сужала права `backlog.md`, а часть нет.

#### Scenario: Права файла очереди не сужаются

- **WHEN** очередь с правами, открытыми шире владельца, правится любой из этих команд
- **THEN** после записи режим файла тот же, что был до неё

### Requirement: Закрытие исходов захода

`stepcast backlog settle --run-dir <каталог> [--file backlog.md]` SHALL проставлять исход `failed` каждому пункту, взятому в этот прогон и оставшемуся без исхода.

Взятые пункты MUST определяться по файлам `item-<дорожка>.json` в названном
каталоге — тем самым, которые пишет `pick --lanes --run-dir`. Пункт, которому
исход уже проставлен (`done` либо `failed`), MUST оставаться нетронутым:
`settle` закрывает заход, а не переписывает его результат. Причина у
проставленного здесь `failed` одна — заход до сведения дорожки не дошёл;
различимые причины несведения проставляет сведение дорожек, а `settle`
остаётся ровно для случая, когда до него дело не дошло вовсе: отмена по
сигналу, остановка по бюджету, гибель шага. Никаких других файлов каталога
прогона команде MUST NOT требоваться — очередь и файлы дорожек её
единственные входы, как и у остальных подкоманд.

#### Scenario: Незакрытый пункт помечается failed

- **WHEN** взятый пункт остался со статусом `in_progress`
- **THEN** ему проставляется `failed` с причиной, называющей, что заход до сведения его дорожки не дошёл

#### Scenario: Проставленный исход не переписывается

- **WHEN** взятый пункт уже помечен `done` сведением дорожки
- **THEN** он остаётся нетронутым, а команда завершается кодом `0`

#### Scenario: Пункты не брались

- **WHEN** в каталоге прогона нет ни одного файла `item-<дорожка>.json`
- **THEN** команда завершается кодом `0`, сообщая, что проставлять нечего, и очередь не правится

#### Scenario: Каталог прогона не назван или не существует

- **WHEN** ключ `--run-dir` не задан либо названного каталога нет
- **THEN** команда отказывает с кодом `2`, а очередь остаётся неизменной

#### Scenario: Файл дорожки без слага

- **WHEN** файл `item-<дорожка>.json` не содержит слага пункта
- **THEN** команда отказывает с кодом `2`, называя этот файл

#### Scenario: Отчёт о закрытии

- **WHEN** заход закрыт
- **THEN** на каждый помеченный пункт напечатана строка со слагом, дорожкой и причиной
