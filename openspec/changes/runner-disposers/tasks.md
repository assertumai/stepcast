## 1. Область ресурсов

- [x] 1.1 `src/core/run/scope.ts`: `ResourceScope { defer(operation, dispose); dispose(): Promise<void>; release(): void }` и `createScope(bookkeeping?: BookkeepingScope)`. Стек пар «имя — операция»; `dispose` снимает LIFO, каждую под `bookkeepAsync` с именем операции; повторный `dispose` — пустая операция; `defer` после `dispose` — `StepcastError` «область уже снята»; `release` очищает стек без вызова. Без журнала операция исполняется напрямую, и её исключение летит наружу — комментарий объясняет, что такая область только для операций, не отказывающих по устройству.
- [x] 1.2 Тесты `test/scope.test.ts`: порядок LIFO; отказ средней операции даёт одно `bookkeeping.failed` с её именем, остальные исполнены; асинхронная операция дождана до следующей; повторный `dispose` ничего не исполняет; `defer` после `dispose` бросает; `release` не исполняет ничего; область без журнала пробрасывает исключение операции.
