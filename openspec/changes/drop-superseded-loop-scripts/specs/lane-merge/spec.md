## ADDED Requirements

### Requirement: Автономные скрипты сведения не несут собственной логики

Прямой запуск `scripts/merge-lanes.mjs` или `scripts/finalize.mjs` SHALL немедленно отказывать, называя замену (`stepcast merge-lanes`, `stepcast backlog settle`), и SHALL NOT изменять дерево запуска, очередь или историю git.

Оба файла раньше реализовывали сведение и расчистку дорожек вне бинаря;
петля их больше не зовёт (`.stepcast/jobs/merge.yml`,
`.stepcast/jobs/finalize.yml` идут через `$STEPCAST_BIN`), но файлы, несущие
прежнюю логику целиком, читаются вторым, расходящимся источником правды при
разборе отказа сведения. Замена тела на отказывающую заглушку убирает этот
риск, не удаляя сам файл физически.

#### Scenario: Прямой запуск merge-lanes.mjs

- **WHEN** кто-то запускает `node scripts/merge-lanes.mjs` напрямую, вне петли
- **THEN** процесс завершается ненулевым кодом, печатает, что команда заменена `stepcast merge-lanes`, и не трогает ни дерево, ни очередь, ни git

#### Scenario: Прямой запуск finalize.mjs

- **WHEN** кто-то запускает `node scripts/finalize.mjs` напрямую, вне петли
- **THEN** процесс завершается ненулевым кодом, печатает, что команда заменена `stepcast backlog settle`, и не трогает ни очередь, ни git
