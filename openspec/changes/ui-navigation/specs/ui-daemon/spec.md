## ADDED Requirements

### Requirement: Витрина отдаётся на любой не-API адрес

Демон SHALL отдавать страницу витрины на любой адрес, не начинающийся с `/api/`, чтобы адрес страницы прогона переживал перезагрузку и открытие в новой вкладке. Отсутствие маршрута под `/api/` MUST называться ошибкой клиенту и MUST NOT подменяться страницей витрины: обращение к API и обращение к странице — разные вещи, и молчаливая подмена превратила бы опечатку в адресе запроса в неразбираемый ответ. Голый `/api` без завершающего слэша SHALL считаться обращением к API: корня у API нет, и страница витрины на этот адрес — та же молчаливая подмена. Разбор адреса страницы прогона MUST быть общим у демона и витрины, чтобы отдаваемый и разбираемый адреса не разошлись.

#### Scenario: Прямое обращение к адресу прогона

- **WHEN** демон получает `GET` на адрес страницы прогона
- **THEN** он отвечает страницей витрины кодом 200

#### Scenario: Неизвестный маршрут API

- **WHEN** демон получает `GET` на несуществующий адрес под `/api/`
- **THEN** он отвечает ошибкой 404, а не страницей витрины

#### Scenario: Голый `/api`

- **WHEN** демон получает `GET /api` без завершающего слэша
- **THEN** он отвечает ошибкой 404, а не страницей витрины

### Requirement: Несобранная витрина отвечает объяснением, а API продолжает работать

Когда собранной страницы витрины на диске нет, демон SHALL отвечать на запрос страницы отказом, называющим команду сборки, и MUST NOT отдавать пустую страницу. Названная команда MUST существовать в `package.json` — отсылка к несуществующему скрипту хуже молчания. Отсутствие собранной страницы MUST NOT задевать `/api/`: обзор, снимок прогона, файлы журнала и поток событий продолжают отвечать.

#### Scenario: Витрина не собрана

- **WHEN** запрошена страница витрины, а `dist/ui-web/index.html` отсутствует
- **THEN** демон отвечает отказом с текстом, называющим команду сборки витрины

#### Scenario: Названная команда существует

- **WHEN** из текста отказа взято имя команды сборки
- **THEN** такой скрипт объявлен в `package.json`

#### Scenario: API не зависит от сборки витрины

- **WHEN** витрина не собрана
- **THEN** запросы к `/api/overview` и `/api/run` отвечают как обычно
