## MODIFIED Requirements

### Requirement: Встроенный экран живёт вкладом в слот и не меняет поведения

Каждый встроенный экран витрины SHALL быть внесён в слот тем же вызовом, каким вносится вклад плагина, и MUST получать свои данные тем, что слот ему передаёт. Поведение такого экрана MUST остаться прежним во всём, что видит пользователь. Выбор экрана MUST идти только через слот экранов: переключателя, перечисляющего экраны по именам, в каркасе витрины MUST NOT оставаться. Ключ слота экранов MUST приходить из цели действующего маршрута, а не из свойства самого экрана. Ключа, которого в слоте экранов нет, MUST быть названной причиной на месте экрана — маршрут ведёт к цели, которой в действующем составе нет, — и MUST NOT подменяться ни экраном по умолчанию, ни пустым местом: экрана по умолчанию у витрины больше нет.

#### Scenario: Переехавший экран работает как прежде

- **WHEN** открыт экран, внесённый в слот
- **THEN** он показывает то же и ведёт себя так же, как до перевода

#### Scenario: Прежнего переключателя не осталось

- **WHEN** открыт любой встроенный экран витрины
- **THEN** он выбран слотом экранов по ключу цели маршрута, а не перечислением имён в каркасе

#### Scenario: Ключа нет в слоте экранов

- **WHEN** маршрут ведёт к цели, которой в слоте экранов нет
- **THEN** на её месте показана названная причина, и никакой другой экран не открывается вместо неё

#### Scenario: Замена встроенного экрана

- **WHEN** вклад со встроенным экраном снят, а на его место внесён другой с тем же ключом
- **THEN** по тому же маршруту открывается новый экран
