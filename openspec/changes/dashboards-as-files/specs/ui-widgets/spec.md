## ADDED Requirements

### Requirement: Виджет — вклад в слот витрины по имени

Виджет SHALL быть вкладом в один keyed-слот витрины, ключ которого — имя виджета, и встроенные виджеты поставки MUST попадать в него тем же вызовом, каким туда попадает виджет пользователя. Имя встроенного виджета MUST быть одним сегментом, а имя виджета-файла — парой «ключ проекта и `id` файла», чтобы пространства имён поставки и проекта не пересекались. Дескриптор слота MUST входить в поверхность, которой пользуется плагин витрины, чтобы вклад виджета не приходилось описывать строкой наугад. Виджет, ключ которого уже занят, MUST отвергаться тем же названным правилом состава слота, каким отвергается повторный ключ любого другого keyed-слота, и MUST NOT исчезать молча.

#### Scenario: Встроенный и пользовательский виджет в одном слоте

- **WHEN** собран состав витрины, и в проекте есть файл виджета
- **THEN** и встроенные виджеты, и виджет проекта значатся вкладчиками одного слота, каждый под своим именем

#### Scenario: Имя проекта не сталкивается с именем поставки

- **WHEN** в проекте заведён файл виджета с именем встроенного виджета
- **THEN** оба виджета доступны: встроенный — по своему имени, файл — по паре «проект и `id`»

#### Scenario: Виджет плагина

- **WHEN** браузерная половина плагина вносит вклад в слот виджетов дескриптором из поверхности плагинов
- **THEN** её виджет доступен дашборду и каталогу наравне со встроенными

### Requirement: Виджет объявляет манифест с параметрами

Виджет SHALL объявлять манифест — заголовок и перечень параметров, — а по каждому параметру MUST называться имя, тип (строка, число, булево или закрытый перечень значений), обязательность, необязательное умолчание и необязательное пояснение. Манифест встроенного виджета MUST объявляться там же, где вносится его вклад; манифест виджета-файла MUST быть экспортом его модуля, потому что знает его только сам файл. Манифест MUST регистрироваться отдельно от вклада — реестром, снимающимся вместе с областью вкладчика, — а не полем дескриптора вклада. Виджет без манифеста MUST считаться виджетом без параметров, а не отказом.

#### Scenario: Манифест виджета-файла прочитан из модуля

- **WHEN** файл виджета экспортирует манифест с двумя параметрами, и его модуль загружен
- **THEN** каталог витрины показывает эти параметры с их типами и умолчаниями

#### Scenario: Виджет без манифеста

- **WHEN** файл виджета не экспортирует манифеста
- **THEN** он доступен как виджет без параметров, и отказа нет

#### Scenario: Снятие вклада убирает манифест

- **WHEN** область вкладчика виджета снята
- **THEN** ни виджета, ни его манифеста в действующем составе не остаётся

### Requirement: Виджет получает параметры и данные витрины props

Виджет SHALL вызываться с props — значениями объявленных параметров и теми же данными витрины, какие каркас раздаёт экрану, — и второго способа доставки данных вкладчику витрина MUST NOT заводить. Значения параметров MUST приходить приведёнными к объявленным манифестом типам, а параметр с умолчанием, не переданный вызывающим, MUST приходить с умолчанием. Виджет-файл MUST получать те же props тем же хостом, что отрисовывает его модуль. Ограничение «виджет вызывается без аргументов и данных ему не даётся» MUST быть снято и MUST NOT оставаться в документации.

#### Scenario: Виджет получает значения параметров

- **WHEN** виджет поставлен на дашборд с объявленными параметрами
- **THEN** его компонент вызван со значениями этих параметров, приведёнными к объявленным типам

#### Scenario: Умолчание параметра

- **WHEN** ячейка не передаёт параметра, у которого манифест объявляет умолчание
- **THEN** виджет получает умолчание

#### Scenario: Виджет-файл получает данные витрины

- **WHEN** виджет-файл проекта отрисован хостом
- **THEN** он получает те же данные витрины, что и экран, и параметры своей ячейки

### Requirement: Поставка приносит встроенные виджеты для дашбордов

Поставка SHALL приносить встроенные виджеты, покрывающие список прогонов, состояние пайплайна, расход за период, запуск пайплайна и вывод шага, и каждый MUST объявлять параметры манифестом, а не быть настроенным зашитыми значениями. Встроенный виджет MUST брать данные из тех же источников, что и встроенные экраны, — из данных витрины и из уже объявленных маршрутов API, — и новых маршрутов чтения ради него заводиться MUST NOT. Встроенный виджет MUST быть отключаем патчем состава той же строкой, какой отключается любая другая строка витрины.

#### Scenario: Список прогонов с фильтром

- **WHEN** виджет списка прогонов поставлен с параметрами проекта и предела числа строк
- **THEN** он показывает прогоны этого проекта не более объявленного числа

#### Scenario: Расход за период

- **WHEN** виджет расхода поставлен с параметром числа дней
- **THEN** он показывает расход за этот период теми же данными, какими его показывает экран расхода

#### Scenario: Кнопка запуска пайплайна

- **WHEN** виджет запуска поставлен с параметрами проекта и пайплайна, и пользователь нажимает кнопку
- **THEN** прогон этого пайплайна запускается, и он появляется в обзоре витрины без перезагрузки страницы

#### Scenario: Вывод шага

- **WHEN** виджет вывода шага поставлен с параметрами прогона, работы и шага
- **THEN** он показывает вывод этого шага тем же содержимым, каким его показывает страница прогона
