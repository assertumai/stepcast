## ADDED Requirements

### Requirement: Встроенная команда CLI — строка дерева

Каждая встроенная команда CLI SHALL приходить в состав строкой дерева, объявленной модулем по соглашению о строке, и MUST быть заменяема и отключаема патчем состава наравне со строкой бэкенда и строкой вида шага. Строка MUST нести ровно одну команду, а её идентификатор MUST выводиться из имени команды, чтобы патч называл команду, а не корпус команд. Замена MUST NOT наследовать вклада заменённой строки: строка пользователя, вставшая на её место, обязана принести команду сама. Конфликт имён команд MUST отказывать прежним текстом и прежней подсказкой, а владелец вклада незаменённой встроенной строки MUST оставаться «встроенным». Отключение строки команды MUST NOT задевать ни одной другой команды.

#### Scenario: Патч заменяет строку встроенной команды

- **WHEN** проектный патч состава заменяет строку встроенной команды модулем пользователя, вносящим команду с тем же именем
- **THEN** вызов этой команды исполняет тело пользователя, встроенное тело не применяется вовсе, и конфликта имён не возникает

#### Scenario: Патч отключает строку одной команды

- **WHEN** патч состава отключает строку одной встроенной команды
- **THEN** в перечне команд её нет, прочие встроенные команды на месте и работают прежним образом

#### Scenario: Плагин объявляет команду с именем встроенной

- **WHEN** плагин вносит команду с именем, которое несёт действующая встроенная строка
- **THEN** загрузка отказывает прежним текстом о занятом имени, называя встроенный вклад и плагин

### Requirement: Доменные команды принадлежат строке движка пайплайнов

Строка доменной команды SHALL объявлять зависимость от служебных сервисов движка пайплайнов и MUST сниматься вместе со строкой-поставщиком каскадом, как всякий её потребитель. Команда, не знающая доменных понятий движка, MUST NOT объявлять этой зависимости и MUST оставаться в составе, где строки-поставщика нет. Принадлежность MUST выражаться объявленной зависимостью, а не местом модуля в дереве каталогов и не перечнем имён внутри ядра.

#### Scenario: Снятие строки-поставщика уносит доменные команды

- **WHEN** область строки, заводящей служебные сервисы движка пайплайнов, снимается
- **THEN** вклады строк доменных команд сняты вместе с ней, а ядерные команды остаются в перечне

#### Scenario: Ядерные команды живут без движка

- **WHEN** собран состав, в котором строки движка пайплайнов нет, а строки ядерных команд включены
- **THEN** осмотр состава и печать конфигурации исполняются как обычно

### Requirement: Перечень строк команд объявляет вызывающий, и его порядок — порядок справки

Перечень строк встроенных команд SHALL объявляться той поверхностью, которая эти команды предоставляет, и подаваться разрешению конфигурации и загрузчику наравне с прочими строками вызывающего. Дерево процесса, который команд не предоставляет, MUST NOT нести ни одной строки команды. Порядок строк в дереве MUST быть порядком регистрации команд и порядком их перечисления в общей справке, а справка дефолтного состава MUST совпадать с нынешней дословно — включая порядок команд, их описания и описания флагов. Пересечение перечня вызывающего с перечнем движка по идентификатору MUST отказывать прежним текстом.

#### Scenario: Справка дефолтного состава не изменилась

- **WHEN** в дефолтном составе печатается общая справка
- **THEN** её текст совпадает с прежним дословно, включая порядок команд

#### Scenario: Дерево демона команд не несёт

- **WHEN** собирается дерево строк процесса витрины
- **THEN** ни одной строки команды CLI в нём нет, а осмотр их не печатает

#### Scenario: Строка плагина вставлена перед строкой команды

- **WHEN** патч состава вставляет строку плагина перед строкой встроенной команды
- **THEN** команда плагина регистрируется раньше и в справке стоит раньше, а прочий порядок сохраняется
