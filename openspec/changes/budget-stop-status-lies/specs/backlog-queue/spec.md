## ADDED Requirements

### Requirement: Закрытие захода коммитит свою правку очереди

Команда, закрывающая заход (`stepcast backlog settle`), SHALL коммитить правку файла очереди, которую сама сделала, в том репозитории, где этот файл лежит. Коммит MUST быть адресован файлу очереди и MUST NOT вносить прочие правки рабочего дерева. Правки нет, файл не отслеживается или лежит вне репозитория — коммита MUST NOT быть, и вывод команды MUST это называть. Отметка исхода дорожки после закрытия захода MUST NOT оставаться незакоммиченной: иначе восстановление дерева её сносит.

#### Scenario: Исход дорожки закоммичен

- **WHEN** `backlog settle` проставил `failed` пункту дорожки, оставшейся без исхода
- **THEN** правка файла очереди закоммичена, а рабочее дерево чисто

#### Scenario: Проставлять нечего

- **WHEN** все взятые пункты уже свели свой исход
- **THEN** команда не делает коммита и говорит, что проставлять нечего

#### Scenario: Очередь не отслеживается репозиторием

- **WHEN** файл очереди не отслеживается репозиторием или лежит вне его
- **THEN** команда не делает коммита и называет это в выводе

#### Scenario: Чужие правки не попадают в коммит

- **WHEN** в рабочем дереве, кроме файла очереди, есть другие изменённые файлы
- **THEN** коммит содержит только файл очереди
