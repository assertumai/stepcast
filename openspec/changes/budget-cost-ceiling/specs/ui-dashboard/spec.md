## ADDED Requirements

### Requirement: Витрина показывает денежный расход

Обзор SHALL показывать по каждому прогону его денежный расход рядом с токенным, а при раскрытии прогона — денежный расход каждой работы и каждого её шага. Цена, не сообщённая бэкендом, MUST помечаться как несообщённая и MUST NOT показываться нулём. Денежные величины MUST браться из состояния прогона и сводки расхода, а новых точек HTTP-API для этого MUST NOT заводиться.

#### Scenario: Деньги в обзоре

- **WHEN** пользователь открывает обзор
- **THEN** у каждого прогона показан денежный расход рядом с токенным

#### Scenario: Деньги работы и шага

- **WHEN** пользователь раскрывает прогон
- **THEN** у каждой работы и каждого её шага показан денежный расход

#### Scenario: Несообщённая цена в витрине

- **WHEN** цена прогона не сообщена ни одной попыткой
- **THEN** витрина показывает признак «не сообщено», а не ноль

#### Scenario: Прогон без записанной сводки

- **WHEN** прогон ещё идёт и `usage.json` не записан
- **THEN** витрина показывает денежный расход по состоянию прогона и не показывает прогон сломанным
