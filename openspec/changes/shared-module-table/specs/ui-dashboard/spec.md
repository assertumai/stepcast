## MODIFIED Requirements

### Requirement: Страница объявляет карту имён и публикует свой экземпляр React

Страница витрины SHALL объявлять import map, по которой каждое имя таблицы общих модулей резолвится в модуль, отдаваемый демоном, и MUST объявлять её до первого модульного скрипта страницы — иначе браузер её не применит. Страница SHALL публиковать свой экземпляр каждого имени таблицы до первой отрисовки, чтобы модуль-переходник нашёл его к моменту импорта любого виджета или браузерной половины плагина. Перечень имён в карте, перечень форм адреса, отдаваемых демоном, и перечень внешних имён при сборке половины MUST выводиться из одной таблицы и совпадать; там, где витрина работает через дев-сервер, адреса общих модулей и виджетов MUST проксироваться на демон, а не отдаваться дев-сервером.

#### Scenario: Карта применена браузером

- **WHEN** страница витрины открыта, и виджет импортирует `react`
- **THEN** имя резолвится в модуль, отданный демоном, а не отказывает как неизвестный спецификатор

#### Scenario: Экземпляр опубликован раньше первого виджета

- **WHEN** виджет импортируется после загрузки страницы
- **THEN** переходник находит опубликованные экземпляры и отдаёт их виджету

#### Scenario: Имя таблицы сверх React

- **WHEN** браузерная половина плагина импортирует `cordis`, `@stepcast/slots` или `@stepcast/ui`
- **THEN** имя резолвится в переходник и отдаёт экземпляр страницы, а не второй экземпляр из бандла плагина

#### Scenario: Витрина через дев-сервер

- **WHEN** витрина открыта через дев-сервер, а демон поднят
- **THEN** адреса общих модулей и виджетов доходят до демона, и всё работает так же, как на собранной странице
