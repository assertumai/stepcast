## MODIFIED Requirements

### Requirement: Отдача содержимого ограничена двумя формами адреса

Демон SHALL отдавать выведенное из пути запроса содержимое ровно по объявленным формам адреса и ни по каким иным: `/widgets/<projectKey>/<id>.js`, `/shared/<имя>.js`, где `<имя>` — сегмент адреса записи таблицы общих модулей, и `/plugins/<id>.js` — браузерная половина плагина действующего состава. Сегменты адреса виджета MUST проверяться как безопасные сегменты пути, итоговый путь файла MUST оставаться внутри каталога виджетов проекта после приведения к реальному пути, и расширение исходника MUST быть фиксированным. Сегмент адреса плагина MUST проверяться так же, отдаваемое MUST собираться только из файлов внутри каталога этого плагина после приведения к реальному пути, и отдаваться MUST только половина плагина, названного действующим составом. Сегмент адреса общего модуля MUST принадлежать таблице и MUST быть безопасным сегментом пути. Любой другой путь под `/widgets/`, `/shared/` и `/plugins/` SHALL давать 404, а перечисления содержимого каталога демон MUST NOT отдавать ни под каким адресом.

#### Scenario: Шаг вверх по дереву

- **WHEN** запрошен виджет, чей идентификатор содержит `..` или разделитель пути
- **THEN** запрос отклонён, файл не отдан

#### Scenario: Абсолютный путь в адресе

- **WHEN** запрошен виджет, чей идентификатор выглядит абсолютным путём
- **THEN** запрос отклонён, файл не отдан

#### Scenario: Символическая ссылка из каталога виджетов наружу

- **WHEN** в каталоге виджетов лежит символическая ссылка `escape.tsx` на файл вне этого каталога, и она запрошена
- **THEN** запрос отклонён, содержимое файла за пределами каталога не отдано

#### Scenario: Путь под /widgets сверх объявленных форм

- **WHEN** запрошен путь под `/widgets/`, не совпадающий с формой виджета
- **THEN** ответ 404, и содержимое каталога не перечислено

#### Scenario: Путь под /shared сверх таблицы

- **WHEN** запрошен путь под `/shared/`, чей сегмент не принадлежит таблице общих модулей
- **THEN** ответ 404, и по нему не видно, что демон отдаёт по соседним адресам

#### Scenario: Небезопасный сегмент в адресе плагина

- **WHEN** запрошена половина плагина, чей идентификатор содержит `..` или разделитель пути
- **THEN** ответ 404, и ничего не собирается и не отдаётся

#### Scenario: Путь под /plugins сверх объявленной формы

- **WHEN** запрошен путь под `/plugins/`, не совпадающий с формой браузерной половины
- **THEN** ответ 404, и содержимое каталога плагинов не перечислено

### Requirement: Имена React резолвятся в модули-переходники с экземпляром страницы

Демон SHALL отдавать по адресам `/shared/<имя>.js` сгенерированные модули-переходники для каждой записи таблицы общих модулей; переходник читает экземпляр, опубликованный самой страницей витрины, и реэкспортирует из него имена закрытого объявленного перечня. Перечень имён каждой записи MUST быть объявлен одним местом и MUST совпадать с тем, что действительно экспортирует модуль этой записи. Переходник MUST отдавать и экспорт по умолчанию для тех записей, у которых он есть у самого модуля, — иначе обычная идиома `import React, { useState } from 'react'` не связывается вовсе. Виджет или браузерная половина плагина, импортирующие эти имена, SHALL получать тот же экземпляр, что и витрина, — так, что состояние хуков внутри них работает, а сервис, заведённый плагином, регистрируется в контексте страницы. Переходник, не нашедший опубликованного экземпляра, MUST отказывать названной ошибкой, называющей причину.

#### Scenario: Хук внутри виджета работает

- **WHEN** виджет держит состояние хуком `useState` и перерисовывается по действию пользователя
- **THEN** состояние сохраняется между перерисовками, то есть экземпляр React у виджета и у витрины один

#### Scenario: Сервис плагина виден контексту страницы

- **WHEN** браузерная половина плагина заводит сервис, наследуя `Service` из `cordis`
- **THEN** сервис регистрируется в контексте страницы и виден зависимым областям

#### Scenario: Перечень имён не разъезжается с модулем

- **WHEN** перечень реэкспортируемых имён записи сверяется с экспортом её модуля
- **THEN** каждое объявленное имя действительно экспортируется, а отсутствующее называет отказ проверки

#### Scenario: Виджет написан с экспортом по умолчанию

- **WHEN** виджет импортирует React идиомой `import React, { useState } from 'react'`
- **THEN** модуль связывается, и оба имени указывают на экземпляр витрины

#### Scenario: Переходник открыт без страницы витрины

- **WHEN** адрес `/shared/react.js` запрошен и исполнен там, где страница не публиковала своих экземпляров
- **THEN** модуль отказывает ошибкой, называющей отсутствие опубликованного экземпляра, а не обращением к неопределённому значению
