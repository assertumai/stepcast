## MODIFIED Requirements

### Requirement: Браузерная половина собирается демоном и отдаётся по объявленному адресу

Демон SHALL собирать браузерную половину плагина по запросу и отдавать её ES-модулем по адресу, несущему идентификатор плагина и версию. Сборка MUST разрешать импорты внутри плагина и MUST оставлять внешними ровно имена таблицы общих модулей, чтобы страница и плагин пользовались одним экземпляром каждого из них. Сборка MUST отклонять плагин, принёсший в бандле собственный экземпляр модуля таблицы мимо её имени, называя файл и имя таблицы. Результат сборки MUST кешироваться по отпечатку каталога и MUST NOT записываться на диск. Ошибка сборки MUST отдаваться исполняемым модулем с разобранной ошибкой — файлом, строкой, колонкой и текстом — и признаком в заголовке ответа, а не отказом запроса: иначе браузер теряет причину. Запрос половины плагина, которого нет в действующем составе — отключённого, отказавшего или не объявлявшего браузерной половины, — MUST получать отказ «не найдено».

#### Scenario: Половина отдана модулем

- **WHEN** страница запрашивает браузерную половину действующего плагина
- **THEN** демон отвечает ES-модулем, собранным из исходников плагина

#### Scenario: Локальный импорт внутри плагина

- **WHEN** браузерная половина импортирует соседний файл своего каталога
- **THEN** он попадает в собранный модуль, и половина работает

#### Scenario: Имя таблицы осталось внешним

- **WHEN** браузерная половина импортирует имя таблицы общих модулей
- **THEN** в собранном модуле остаётся внешний импорт этого имени, а его код в бандл не попадает

#### Scenario: Свой экземпляр общего модуля в бандле

- **WHEN** браузерная половина приносит собственную копию модуля таблицы мимо её имени
- **THEN** сборка отклонена с названием файла и имени таблицы, и половина странице не отдаётся

#### Scenario: Ошибка сборки

- **WHEN** браузерная половина не собирается
- **THEN** ответ — успешный исполняемый модуль с разобранной ошибкой и признаком в заголовке, а соседние плагины отдаются по-прежнему

#### Scenario: Половина отключённого плагина

- **WHEN** строка плагина отключена патчем, и запрошена её браузерная половина
- **THEN** ответ — «не найдено», и код плагина не отдаётся
